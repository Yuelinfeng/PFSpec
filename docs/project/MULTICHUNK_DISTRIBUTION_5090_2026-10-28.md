# 5090 多 Chunk 场景采样分布核验

## 结论

本次 Target 和 W1 的图片不同，可以由两条路径消耗随机数的顺序不同解释。代码和有限上下文的数值结果支持 W1、Rescue 按 Target 条件分布采样；尚不能仅凭这批结果证明 12 米场景所有可能路径都完全一致。树形计算与普通 Target 的浮点结果存在微小差异，不能声称逐位完全相同。

## 范围和结果

- 沿用 2026-10-28 的 60 × 60 列场景、temperature 0.9、top-p 0.9、seed 0、最多五次空列重采样和原 checkpoint。只增加诊断程序，没有改场景生成程序、模型或权重。
- 查看 Target 的采样、位置类型限制、W1 和 Rescue 的候选接受、剩余概率抽样、结束符处理及场景调度。五次重采样的温度均为 0.9；两条投机路径采用相同场景参数。
- 从 W1 保存的列内容重建前缀，共有 447 个与已保存调用种子和前缀长度相符的候选。抽取 5 个扩展、2 个单列重采样和 1 个分组重采样前缀，长度 300–5950 token。原始调用前缀未保存，种子和长度一致不能单独证明前缀内容完全相同。
- 对 8 个前缀完成 80 组普通 Target、W1 树和 Rescue 树的概率比较，包含备用位置分支；top-p 保留集合均相同，最大总变差距离为 2.0862×10⁻⁶。位置点候选的接受和剩余抽样复算最大差异为 7.02×10⁻⁸；Feature 候选最大差异为 3.24×10⁻⁸。这里的差异包含有限精度运算影响。
- 用原始启动预算 16000 和 seed 0 重放 W1 启动流，产生 4339 token 并自然结束，与原记录的数量和结束状态一致。原始完整启动流未保存，因此不能据此声称重放 token 逐个相同。重放前缀长度 0、2、32、96、4338 的 Target 隐式与显式类型计算所得概率一致；结束前 EOS 概率为 1。
- 用重放启动流重建第一条跨块启动前缀，长度 2876、seed 163921、预算 800，均与原调用记录相符。9 组普通 Target 与 W1、Rescue 树的概率对照最大总变差距离为 8.74×10⁻⁷，top-p 保留集合相同；原始前缀内容未保存。
- 在重放得到的 4338 token 结束前缀上，W1 和 Rescue 均拒绝位置候选并生成 EOS；原 Target 的有效新增 token 为空，与场景包装层去除 EOS 的行为相符。末尾 16 个位置前缀也已复算点候选概率。小词表概率计算自测 9/9 通过。

## 限制

这是一组前缀级与分支级结果，未覆盖全部场景前缀，也没有进行多 seed 整场分布统计。浮点微差可能在其他前缀影响 top-p 边界；现有结果不能推导完整场景分布误差的上限，也不能单独证明图片差异只由随机数消耗造成。W1 与 Rescue 的原始完整场景 token 一致，不能代替 Target 分布验证。
