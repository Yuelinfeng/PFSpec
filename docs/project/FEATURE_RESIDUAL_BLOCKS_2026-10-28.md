# Feature 残差块深度实验

日期：2026-10-28。状态：三组训练、解码等价验证、240 次在线比较及前向耗时测量均已完成。

## 目标与模型

用户确认保留当前 FeatureStateDraft 的完整结构，新增 3 个、5 个残差块，对应总计 4 块、6 块。原块内含 3 个 Linear；本次层数口径为残差块数量。

原模型为 step12000，原有 Position Ranker 与 Target 不变。新增块各自拥有 LayerNorm、1024→256 输入层，以及 LayerNorm、512→512→512→1024 的残差分支；token embedding 与固定 Feature 输出权重共用。新增块的状态归一化与压缩层复制原参数；残差分支内部采用默认随机初始化，最后一个 Linear 的权重和偏置从零开始。原块参数保留，所有块参与训练。

可训练参数：原模型 2,864,384；新增 3 块为 6,812,672；新增 5 块为 9,444,864。固定输出权重不计入这些数字。

## 数据与训练

沿用原有直接 Target 监督：400 条训练轨迹、418,021 行；50 条验证轨迹、46,893 行。完整轨迹分组，本轮在线评价输入不用于新增训练或权重选择；沿用既有轨迹划分，不将其扩称为全新场景测试。原始 FP32 教师概率来自 GPT vfront，训练温度 1；接受率策略 temperature/top-p 均为 0.9。

三个训练组为原模型等量续训、新增 3 块、新增 5 块。均从 step12000 出发，各训练 1,200 步，seed 24690，每步两条轨迹、256 行分块。目标沿用完整教师分布交叉熵加 2 倍策略 TV；AdamW、学习率 1e-5 余弦降至 1e-6、权重衰减 0.01、梯度范数上限 1。BF16 训练，FP32 验证，TF32 关闭。每 400 步在完整验证集评价，以逐行分布重合度选模型，并保留训练前权重参与选择。

这是一轮有限续训，用于判断增加残差块是否产生可测变化，不代表各结构均已达到充分训练状态。

## 首轮新增块幅度诊断

新增 3 块训练 1200 步后，取一条验证轨迹的前 64 行在 CPU 上观察各块。上一 Target 状态 RMS（均方根幅度）为 365.53，原残差分支输出 RMS 为 1402.72；三个新增分支输出 RMS 分别为 0.002811、0.002811、0.002656。新增输出层权重最大变化约 0.00194，参数确有更新，但对原隐藏状态的改变量很小。原块末个 GELU 输出 RMS 为 81.23，新增块对应值约 0.104，显示内部激活尺度存在明显差异。

该观察限这一批 64 行。它说明零输出初始化、随机内部参数和较低续训学习率使新增块在本轮内接近恒等映射，不能将有限续训中的微小变化解释为网络深度没有作用。在线结果已完成，见下表。证据保存在服务器 `block_scale_diagnostic.json`。

## 在线接受率与执行成本

30 来源、64/256 前缀、seed 57101、每次最多 512 个新 token，四组各 60 次，总计 240 次。所有组均使用 W1，Target 与 Feature 前向使用 CUDA Graph；FP32、TF32 关闭。不同方法顺序轮换，GPU 串行执行，计时包含前缀、正式首次建图、提案、验证、恢复与状态维护，排除模型载入和结果写入。

加 3 块与加 5 块相对等量续训的吞吐 95% 区间分别为 [0.996595, 1.003013]、[0.997931, 1.004096]，均包含 1。前向耗时为 CUDA event 区间的中位数，含输入复制及可能的 CPU 发起间隔，排除采样和 Target；完整解码耗时没有表现出可靠变化，不能据单独前向耗时推出同等幅度的整体变慢。

加深两组与等量续训组的 60/60 对输出、全部动作计数相同，实际验证 Feature 和接受数也相同。元数据确认它们分别载入 add0/add3/add5 的所选权重，可训练参数分别为 2,864,384 / 6,812,672 / 9,444,864；Feature 提案图均实际回放 11,235 次，未出现提案图回退。

续训三组相对原 step12000 的在线接受率点值低 1.4487 个百分点，按 30 来源配对重采样的 95% 区间为 [-3.4984, 0.3559] 个百分点，包含零。不同训练权重会改变轨迹，离线小幅改善与这一在线点值变化不能直接视作矛盾，也不能解释成加深造成了下降。加深相对等量续训的接受率差在本批观测为零。

## 验证、结论与限制

- 三种结构在训练前与原模型输出相同；普通/图前向相同；新增块收到训练更新；保存读取后的输出相同。
- 四组模型、两个前缀，共 8 组普通/图解码的输出和动作对照全部通过。
- 本机从 240 条原始记录独立复算各组接受与验证总数、接受率及 60 对输出/计数，与汇总一致。
- 三个模型均训练到 step13200，读取完整 50 条验证轨迹后选中的都是最后一步；每组新增训练样本呈现次数相同，为 2,508,126 行。
- 当前有限续训没有观察到增加残差块的接受收益。新增块输出远小于既有状态，说明这组初始化和学习率下新容量尚未形成明显的状态改变量；这不支持否定深度本身。
- 后续应优先研究新增块的内部初始化、状态幅度和分组学习率，再比较充分训练的深度收益。当前只覆盖一个训练种子和一个解码种子，未验证多 chunk 或三维质量。

原 step12000 继续保留为当前推理模型，新增权重未替换既有入口。完成后 4090D 显存为 2 MiB，利用率 0%。
