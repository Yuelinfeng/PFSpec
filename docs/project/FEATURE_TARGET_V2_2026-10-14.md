## 数据与训练设置

使用既有 rollout500 的 400 条训练、50 条验证轨迹。覆盖每条轨迹的全部可用 Feature 位置；第一个 Feature 缺少上一 P/F 对，由实际解码中的 Target 直接生成，因而不进入状态模型的监督行。Target 状态使用完整因果前缀，标签使用原始温度 1.0、不截取的 FP32 概率。新的训练行与此前 GPT 完整分布标签逐项比较，确认来源和位置一致。验证也覆盖全部可用行。

上一轮迁移实验每条最多抽取 64 个 Feature 位置，标签温度为 0.9；其损失中的教师分布采用 top-p，而学生采用完整 softmax。该 Target 对照与本版本的全部位置、原始完整分布和两侧采样策略 TV 有明确差异。

本版本从旧轻量权重直接训练三个预先确定的阶段：

| 阶段 | 步数 | 初始学习率 | 目标 |
| --- | ---: | ---: | --- |
| 完整分布 CE | 1200 | 3e-5 | Target 温度 1.0 的全部 Feature 概率 |
| 低学习率 CE 续训 | 1200 | 1e-5 | 保持完整分布监督 |
| 正式采样策略 TV | 1200 | 1e-5 | 完整 CE 加权重 2 的 TV |

每步两条轨迹，全部 Feature 行参与更新，按行数加权；分块 256 行累积梯度。AdamW、weight decay 0.01、梯度裁剪 1.0，每阶段学习率余弦降至初值的 0.1。BF16 训练，FP32 评价。阶段种子分别为 24684、24686、24688。

TV 为两分布概率差绝对值之和的一半；教师和学生都使用 temperature=0.9、top-p=0.9。沿用成功 GPT 续训中的 `feature_policy_tv`，支持范围的选择不传播梯度，保留概率的计算传播梯度；完整 CE 继续给其余类别提供学习信号。

按完整验证集的按位置重合度选择权重，包括旧起点。训练预算固定，测试不用于调整教师、结构、损失或阶段。结果同时报告按轨迹平均重合度，避免混用统计权重。
