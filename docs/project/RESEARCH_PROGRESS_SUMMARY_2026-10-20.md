# GaussianGPT 阶段研究汇总

截至2026-10-20 10:26（UTC+8），Position Ranker + step12000 Feature MLP + 原Target仍是已有证据最充分、实际表现最好的完整方案。正式固定窗口解码约1.67–1.71×，完整单chunk生成、解码与渲染约1.53–1.57×。真实可靠的2×尚未达到。用户希望把当前方案作为Motivation，后续在P/F分离的思想下发展完整方法。

## 已经建立的主方法与正式结果

Position Ranker利用位置序列规律，低成本提出Position；Feature MLP读取上一Position的Target隐藏状态、历史Feature和当前候选Position，预测当前Feature分布。两者由原Target验证，拒绝时通过剩余概率采样和缓存恢复继续生成。Feature MLP已经使用上述条件信息，后续设计需要说明新增信息或监督带来的具体作用。

阶段E在30来源、56裁剪、三个采样种子、五方法下完成2160次FP32评价。PF/Target来源等权速度为1.71250×，95%区间[1.68044,1.74402]；全体token与时间合计得到1.69675×。P/F接受率为92.64%/33.26%。同轮P-only为1.43773×，PF-D8为1.46646×，GPT-D8为0.93815×。

后续30个新来源、666次Token评价中，PF/Target为1.674× [1.642,1.706]。两批结果分别保留，不能拼成一个更高的加速比。阶段F完整补全至NPZ与PNG写出的PF/Target为1.569× [1.318,1.852]；后续完整三维批次为1.530× [1.340,1.721]。两批PF/P-only完整流程区间均包含1，额外端到端收益仍有不确定性。

这些结果覆盖单个20×20×20 latent chunk。完整自然EOS和三维导出已有结果，但生成区域画质、多chunk接缝及完整房间延伸仍缺充分评价。Target/VQ预训练来源ID资料不完整，无法确认其与所有评价来源完全隔离。

证据：[真实源码与结果对应](RESEARCH_EVIDENCE_AUDIT_2026-10-16.md)、[多场景研究记录](PF_MULTISCENE_RESEARCH_PLAN_2026-10-14.md)、[后续30来源结果](NEXT_ROUND_RESULTS_2026-10-17.md)。

## 网页研究循环Round01：精确双Feature候选

先完成连续剩余概率采样的数学验证：2207组p/q与60463组三元组合精确误差0，另有高维binary64与辅助随机抽样。明确区分第二候选被接受的条件分布和包含再次拒绝的最终混合分布。44条调度轨迹通过；这些结果支持概率与控制流，不代表CUDA性能。

真实诊断在193.622秒内完成，新增训练0；采集480条4096维p/q，narrow/wide各48条真实P2分支条件。第二接受重合度约15.22%/14.31%，每轮联合有利事件点估计约8.56%/5.71%。有限配对中2与4 token前向成本接近，且配对只有2个唯一上下文、1来源。

当前没有得到跨轮减少实际Target调用的明确机制，因此未实现完整惰性双候选解码，也没有宣称新的总加速比。实际64文件结果包已上传原Chrome网页并被读取。

证据：[R1实际概率与成本](artifacts/pf2x_loop_20261019/round01/cost_probe_review_20261020/FEASIBILITY.md)。

## 网页研究循环Round02：按P/F合并Target输出计算

实现PF-TypedVerify候选，将同类型token行的输出计算合并，保持原权重、FP32、采样、位置限制、RoPE与有效KV语义。候选在独立进程临时装载，原生产源码未改。

4来源8真实上下文、1/2/4 token各96配对，736次前向、728次恢复、688次数值比较全部通过，总墙钟65.529621秒。真实GPU有限logits最大差1.93119e-5，policy最大逐项差3.57628e-7，hidden/RoPE/有效KV比较通过。

## 下一步应解决的研究问题

现有证据支持“低成本Position提案 + 有效Feature条件预测”的分工。更复杂结构、更长训练和更高局部接受率，均需落实到每轮实际推进与完整耗时。下一轮应先给出达到2×所需的Feature质量、可承受Draft成本，以及候选如何减少Target工作或提高有效推进的明确机制，再确定数据、监督和结构。

以历史1.7125×点估计作粗略参考，保持Target和输出工作量不变时，PF总耗时还需减少约14.4%才能到2×。这只是研究缺口的换算，正式结果仍须同轮原Target/PF/候选对照、独立来源区间、长度/EOS及三维有效性。

Round03完整网页任务书尚未取得。后续继续复用三名gpt-6-luna/max，按网页明确任务执行，不重复已有续训、R1/R2诊断或追加未经计划的GPU实验。原源码历史、数据、权重和实际结果均保留。
