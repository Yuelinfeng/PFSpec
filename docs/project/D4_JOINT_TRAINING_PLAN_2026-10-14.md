## 目标与已有依据

训练能同时提出 Position 和 Feature 的 D4，直接学习原始 Target，衡量接受能力与运行成本的共同变化。主指标是同轮 Target 归一化的真实前缀解码速度，同时与 D8 联合 Gamma2 和既有轻量 Feature Draft 加 Position ranker 比较。

D8 真实前缀 Gamma2/4/6 的 Feature 接受率为 54.3726%/53.6912%/53.6286%，速度为 0.9696×/0.9127×/0.8141×。D4 沿用 D8 有效的完整 Feature 分布监督及 TV 优化，教师始终为 `checkpoints/gpt_vfront.ckpt`。D8 仅参与结果对照。

规划时已读取远端 `/root/workspace/GaussianGPT` 的训练代码、历史计划和运行产物；RTX 4090 为 2 MiB、利用率 0%。已查找 checkpoints、profiling、draft_a/runs、logs 中包含 D4 标识的资产，发现 D4 配置和随机初始化测速记录，尚未发现可复用的 D4 预训练权重。D8 的起点为 38-epoch ASE 预训练权重，两者起点不同，应在结论中保留这一限制。

旧 FP32 单 token 前向测速中，D4 为 9.372M 参数，1024/2048/4096 上下文耗时分别为 3.3228/3.3703/3.9067 ms；D8 为 5.4422/5.4226/6.6583 ms。D4/D8 约为 59%–62%。这份随机初始化的旧测速未覆盖当前完整提案循环。按上一轮有效成本模型和 60% 比例、相同接受行为估算，Gamma2/4/6 约为 1.19×/1.20×/1.12×。40% 耗时比例下的 1.4× 属于更乐观的情景，不能当作本轮承诺。

模型采用现有 `conf/model/gpt_draft_d4.yaml`：4 层、256 维、4 个注意力头和 4 个 KV 头，context 16384。保留原词表、序列格式、位置约束、RoPE、BOS/EOS 及 `NanoGPTGaussianModel`。执行时统计实际参数量。

按当前资产从随机初始化开始，seed 为 24690。D8 的 512 维权重不直接裁成 D4 的 256 维权重。首轮通过较充分的初始学习补充 D4 缺少预训练起点的差异，结果只能回答这套 D4 训练方案是否有效，不能单独归因于层数。

复用 `draft_a/runs/rollout500_20261013/` 的原划分：400 条训练、50 条验证、50 条历史对照轨迹。训练集有 836842 个正文 token、61 个自然 EOS、418421 个 Feature 位置。训练与选模不使用真实 VFront 裁剪。

50 条历史对照轨迹和现有真实场景已经被多轮查看，本轮用于同条件复测，不能称为全新的独立泛化证据。验证集仅用于模型选择，历史对照集只在选定权重后运行。

完成少量训练更新以确认损失、梯度、更新后的参数及保存恢复正常，并覆盖最长训练轨迹。验证词表、序列类型、逐 token/分块、缓存退回和 Target 自身提案。短运行记录单独保存，不混入正式训练步数。模型和数值有效时完成本轮预算；成本比例偏高作为研究结果记录，不凭单个测速数值取消已授权实验。

## 训练预算

总预算为 8600 次优化器更新，一条随机种子路线。每步累计两条完整轨迹的梯度，按有效预测 token 数加权；不通过截短序列减少历史上下文。

| 阶段 | 全局步数 | 更新次数 | 学习率 | 目标 |
| --- | --- | ---: | --- | --- |
| 初始学习 | 1–5000 | 5000 | 200 步预热至 3e-4，再余弦下降至 3e-5 | P/EOS 标签 CE + 全部 F 概率 CE |
| 完整分布精调 | 5001–6200 | 1200 | 3e-5 余弦下降至 3e-6 | 同上，复用 D8 第一阶段设置 |
| 低学习率续训 | 6201–7400 | 1200 | 1e-5 余弦下降至 1e-6 | 同上，保留 P/F 对齐 |
| 接受能力优化 | 7401–8600 | 1200 | 1e-5 余弦下降至 1e-6 | 上述 CE + 权重 2 的 Feature policy TV |

损失沿用 D8 定义：P/EOS 的标签 CE 与全部 F 的完整分布 CE 求和后，除以所有有效预测 token 数。最后阶段额外加入两侧正式采样策略的 Feature 总变差；策略为 temperature=0.9、top-p=0.9，沿用现有可求梯度实现。

采用 AdamW、weight decay=0.01、梯度裁剪 1.0、BF16 训练和 FP32 评价。阶段之间连续保存模型、优化器、步数及随机状态；学习率按表切换。若完整执行、每步两条且每轮遍历 400 条，则共 43 次训练集遍历，累计 35986829 个预测位置，其中 Feature 17992103 个。阶段曝光量单独记录，避免将累计量误写为唯一 token 数。

初始学习在 step0/1000/2500/5000 记录固定验证位置的 P/F 重合度与 CE；后续每 600 步记录同类指标。使用完整 50 条验证轨迹的既有固定位置清单，并如实记录每类位置数，不称为全部验证 token。固定训练子集同步记录，用于观察训练与验证差距。每个阶段的末尾权重保留。

首轮不因历史对照或真实场景结果追加训练。若 8600 步后仍有持续收益，再依据本轮验证曲线提出下一轮预算。

## 结果解释与操作范围

接受率目标是观察能否保留接近 D8 的 Feature 对齐能力，不承诺超过 50%。有用的第一步是同轮速度超过 Target；更高目标是接近或超过已有轻量路线。上一轮轻量路线约 1.45×，正式结论只使用本轮复测值。

若 D4 成本明显下降而速度仍未提高，应结合每轮接受长度判断容量损失；若接受率保留但成本比例高，应定位提案循环及调度开销。只有一个真实场景，缺少跨场景平均收益证据；首轮亦不覆盖生产 BF16 解码或完整三维重建、渲染耗时。新增独立场景和从相同预训练预算比较容量属于后续研究范围。

计划复用原损失与解码函数，为 D4 新增独立训练、成本测量和评价入口，避免改动已完成 D8 实验的默认行为。本地源码副本拟放在 `patches/d4_joint/`；远端结果拟放在 `/root/workspace/GaussianGPT/draft_a/runs/d4_joint_20261014/`。当前只写计划，尚未创建这些运行产物。
