# N2 CPU阶段决定

当前决定：停止当前 N2 路线，不启动 GPU 或在线运行。8 个模型均完成 150 次更新，共 1200 次；CPU 拟合程序墙钟27.709725秒。独立逐行复算通过，errors为空。

本轮输入是 R1 的 480 条 Ranker 条件记录。每条来自一次实际接受 P1 的轮次，十个来源各 48 条；这些来源此前都用于研究探索，因此本轮留源结果仅反映当前流程内的诊断，不作为全新独立确认。P1 加权分数也只适用于这个已接受 P1 的样本集合，不能直接解释成全部生成轮次的推进率。

来源按 scene ID 字典序切为 6/2/2：Fit 288 行、Tune 96 行、Hold 96 行。完整来源列表见 `docs/project/artifacts/pf2x_loop_20261019/round03/source_manifest.json`。只用 Fit 拟合；S1–S4 各用种子 17、29 训练 150 次更新，共 1200 次更新。每种方法在 Tune 上按来源等权的 `p1_accept_probability × feature_overlap` 选择一个种子，分数相同选 17；不挑选较早训练步。选定后，Hold 只为每种方法的选中模型计算一次结果。

比较包括 S0 旧 q、S1 旧 logits 统计残差、S2 加入最近六个已提交序列 Feature、S3 加入已提交六面邻居、S4 加入同一历史内的非六面 PF。S1 是旧 logits 统计残差模型；原 MLP 的同数据重训未纳入比较。S3 与 S4 的有效数量和 mask 必须一致。S4 保留真实坐标与序列年龄，以同一历史内的非六面 PF 替换六面邻居；本轮没有进行坐标打乱。

主分数为来源等权的 `mean(p1_accept_probability × feature_overlap)`。同时报告来源等权普通 overlap，以及每个来源内按 P1 概率归一后的加权 overlap。Feature overlap 按 `sum(min(p_F, q_F))` 计算；q 使用温度 0.9、top-p 0.9 的最终策略分布。PCA 只使用 Target Feature embedding，不使用 `p_F`、`q1`、`raw_logits` 或标签来确定表示。

S3 比 S0 高 0.879037 个百分点，比 S1、S2、S4 中最高的 S2 高 0.707884 个百分点；两条 Tune 来源相对 S0 分别为 +1.893430 和 −0.135356 个百分点。因此未达到预设的 +3 个百分点、相对最佳学习型对照 +1.5 个百分点，以及两条来源均改善这三项条件。SMIX 0.1 的 Tune 分数略高于 S3；它是固定混合参照，未参与原定模型选择条件。当前结果支持停止本轮空间模块，不据此推断更大的空间表示无效。

Hold 的普通 overlap：S3 为 0.3767282757，SMIX 0.1 为 0.3819809244。该结果仅作选种后的留源诊断，不用于本轮方法选择。S0的Hold普通overlap为0.3687874135，S3提高0.794086个百分点。

0.5 毫秒目标属于后续硬件测量，本轮 CPU 结果无法验证。此次比较未测端到端吞吐或 2× 速度。结论范围限于这 480 条记录上的 overlap 变化；记录均来自此前参与研究探索的来源，且只包含实际 P1 接受样本，P1 加权结果不代表总体推进率。结果限定于本轮 PCA32 和当前小模型；其他空间条件设计仍需单独验证。
