# 网页确认的N2执行参数

2026-10-20，电脑Chrome原研究对话已完整回复《Round N2：空间条件Feature Draft零GPU小实验执行方案》。本页记录可执行参数；细节未由网页指定的实现选择在末段明确列出。

对话：https://chatgpt.com/g/g-p-6ab0f2354ef88191af84c1dd97a89d90-gaussiangpt/c/6ad1b79f-7bc4-83e8-a9d1-d41896fb2aed

只执行现有480条Ranker条件记录的信息筛选。GPU为0，不运行Target前向，不改生产PF或现有权重，不展开LFQ或固定短名单树。

输入为原Target checkpoints/gpt_vfront.ckpt中的4096×1024真实Feature输入embedding、R1 contexts.jsonl与vectors.npz。词表全局8000:12096。只根据词表embedding做PCA降至32维并保持不变，不读取目标概率决定表示。

S0为旧q。S1只用旧logits及其统计；S2增加最近至多6个已提交序列Feature；S3增加已提交六面邻居；S4保持S3有效数量和mask，替换为同一样本历史内的非六面邻居。简单邻居混合沿用Round03系数0.1，不重选。

各邻居以32维embedding、三维相对坐标和归一化序列距离，经两层隐藏32的小MLP，再作单头32维注意力池化。结合旧q统计产生32维类别条件向量，与各类固定embedding点积得到4096类残差。最终线性层零初始化。S1–S4使用相同模型框架和总参数量，S1邻域输入置零。

AdamW，学习率5e-4，权重衰减0.01，batch32。每配置每种子150次更新，种子17和29，共8模型、1200次CPU更新。损失为P1理论接受概率加权的Target软分布KL，加残差L2。梯度使用未截断softmax；评价使用原温度0.9、top-p0.9。不可再次softcap已有raw_logits。

按来源字典序6/2/2，288/96/96行。Fit拟合，Tune按来源等权加权overlap选两个种子中的模型，固定150步，不挑中间步。Hold最后统一评分一次。所有来源此前已参与研究探索，仅作为当前拟合的留源诊断。480条原采集只保留实际P1接受轮次，加权分数不能外推总体轮次推进率。

主要分数明确为来源等权mean(w*overlap)，另报普通overlap及归一化加权overlap。继续条件在Tune：S3比S0至少增加0.03，比S1/S2/S4最佳至少增加0.015，两个Tune来源各自均改善。0.5毫秒是后续GPU额外成本的设计目标，此轮CPU不能验证GPU延迟。条件不满足则停止当前模型；条件满足也只提交网页审阅，不自行启动GPU。

实际执行合计上限1200秒，含数据读取、表示计算、全部拟合与结果保存；训练软限720秒，统一由主代理控制。代码编写、等待网页与人工式审阅不算模型执行时长；此前只读元数据与邻居计数的实际命令耗时另列，不隐去。

网页未指定的实现选择：残差L2系数1e-4、倍率固定1、S4取样seed32043；8维统计为raw均值/标准差/最大/最小、前两名间距、归一化q熵、q首项概率、q前8项质量，标准化仅用Fit统计。S2相对坐标为0；S3/S4使用真实相对坐标除19；年龄除本行已提交PF对数。PCA32用全词表统一RMS数归一，保留原矩阵和该数。种子分数相同时选17。零残差路径原样保留q。
