# G3：连续在线生成结果

## 结论

512-token 主测中，Gap/PF-K2 的来源等权几何平均为 **1.006×**，95% 来源重采样区间为 **[0.991, 1.022]**，10 个来源中 6 个更快；当前不能确认短窗口净收益。2,048-token 长窗口中，Gap/PF-K2 为 **1.026× [1.008, 1.044]**，10 个来源中 7 个更快，达到计划中进入 G4/G5 的条件。

两组数据均来自 D0 的既有 10 个开发来源。长窗口结果提供了继续研究的信号，不构成新来源确认；512-token 主测仍然跨过 1。

## 样本与测量

短窗口完成 672 次生成：56 个固定前缀、3 个种子、Target、P-only、PF-K2、Gap 四种路径。长窗口完成 90 次生成：10 个来源、每来源 1 个初始前缀、3 个种子、P-only、PF-K2、Gap 三种路径。另有 32 次短测通过。计时覆盖缓存分配、前缀预填与解码调用，不含模型及数据加载；提前 EOS 的实际长度单独记录。

| 窗口 | 方法 | 汇总吞吐 | 来源等权比 PF-K2 | 来源胜出数 |
|---|---|---:|---:|---:|
| 512 Token | Target | 71.88 Token/s | 0.615× | 0/10 |
| 512 Token | P-only | 100.61 Token/s | 0.861× | 0/10 |
| 512 Token | PF-K2 | 116.84 Token/s | 1.000× | — |
| 512 Token | Gap | 117.60 Token/s | 1.006× | 6/10 |
| 2,048 Token | P-only | 104.11 Token/s | 0.893× | 0/10 |
| 2,048 Token | PF-K2 | 116.72 Token/s | 1.000× | — |

Gap 的 PF 使用率在短窗口为 77.6%，长窗口为 74.2%。Feature 在线接受率分别为 37.64% 和 33.17%。同一固定 seed 下不同方法不要求逐 Token 相同；本轮各方法均走原有 Target 接受与残差抽样路径。

## 范围与下一步

本结果是 Token 生成测速，未包含 VQ 解码或 Gaussian 输出。D0 的 10 个来源已用于 B1 分层分析，不能作为独立确认集。按预设路线继续做 G4 的等频随机、反向规则和路由计算成本对照，并用额外未参与 B1 的来源开展 G5 稳定性评测。G6/G7 是否继续，取决于 G4/G5 的结果与新来源完整生成情况。
