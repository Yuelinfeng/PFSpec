# 备用位置质量的可辨识性

本轮只核对已有开发轮次、既有 ridge 权重与报告，以及两个成本采样文件；没有访问新来源结果，也没有重新拟合权重。主要开发集包含 10 个来源、1,908 条逐轮记录，其中 772 条非诊断记录具备 k=1 备用动作；另有 50 条专用于成本采样的诊断记录。拟合报告按来源留出，8 个来源训练、2 个来源验证。

## 质量口径与分布

这里的备用质量取 `target_mass_by_token[b]`。候选表中 `ranker_rank=0` 是 Ranker 主候选，对应 `p_main`；`ranker_rank=1` 是最高分备用，`ranker_rank≥2` 是更低名次备用。对 point proposal，主候选 `q=δ_main`；当备用位置 `b` 与主候选不同，未归一 residual mass 就是 `p(b)`。因此表中的值是不以“主候选被拒绝”为条件的 Target policy 质量，不能与拒绝后的归一化概率混用。

在 772 条非诊断、k=1 可用的上下文中，453 条 `p_main=1`，这批记录所有备用 mass 都为零。另 319 条具有正的 P1 residual mass。ranker rank1 备用 token 的目标质量均值为 0.1056，中位数为 0，75 分位仍为 0，90 分位为 0.4545；600/772（77.7%）为零。候选表里所有备用 mass 的总和均值为 0.1308，中位数为 0。对有正 P1 residual 的记录，候选表平均覆盖其 residual mass 的 45.9%，中位数 29.8%；115/319 条的候选表质量为零。

按 `p_main` 分箱后，ranker rank1 与次级候选质量仍有差异。表中的 `best rank≥2` 在没有次级候选时按零计，因此它表示当前候选表可选的次级质量，而非完整位置空间的最大值。

## 已有 ridge 的验证表现

我从保存的权重直接重算两个留出来源上的 297 个候选标签，没有重新拟合。mass ridge 的 MAE 为 0.1455，RMSE 为 0.2231；仅用训练集目标均值 0.1044 的常数预测器，MAE 为 0.1510、RMSE 为 0.2233。ridge 有小幅 MAE 改善，RMSE 几乎持平。实际验证 mass 均值为 0.0756，预测均值为 0.1185；预测与实际相关系数为 0.242，校准斜率为 0.560。

直接恢复价值模型的 297 个留出标签里，23 个为正，正值占 7.74%。value ridge 的 MAE 为 0.6158ms、RMSE 为 0.9890ms，均高于训练均值 0.3681ms 的常数预测器（MAE 0.5930ms、RMSE 0.9784ms）。模型平均预测 0.4359ms，高于验证标签均值 0.2819ms；校准斜率为 0.482。实际 mass 标签与同候选的随机实现 value 标签相关系数为 0.865，但每上下文只有一个开发 seed，不能由此估计稳定的条件价值。

拟合报告中 206 个留出上下文里，direct value 与同动作数 Ranker 的候选 ID 在 206/206 条一致；mass-cost 与同动作数 Ranker 也没有候选 ID 差异。direct value 与固定一个备用动作有 54/206 条不同，报告例子显示主要差异来自是否选择空动作。因此当前 ridge 尚未证明能把候选质量差异转成稳定的候选身份选择。

## 恢复代价与备用质量上限

非诊断 W1 记录中有 197 次实测 P1 恢复，时长均值 3.623ms、标准差 0.108ms、中位数 3.652ms、90 分位 3.692ms。主体相当集中。对这 197 条实际发生恢复的记录，使用同一条记录的实测时长计算 `p(b) × recovery_ms`，ranker rank1 的均值为 1.268ms，最好次级候选为 0.316ms。次级候选相对 rank1 的正向概率乘时延差额在 34 条高于零、51 条相同、112 条低于零；截为非负后的 197 条均值为 0.263ms。它只描述“本轮确有 P1 恢复”的样本，并假设备用命中后省下同一时长，不能当作总体期望或实测净加速。

开发集中另有 50 条 `diagnostic_only` 的 k=1 shape probe，记录 3 次重复 shape 成本；其中 16 条同时记录到同轮 P1 恢复时延。用这些记录作局部 `p × 实测恢复时延 − extra_shape_cost` 算术对照，ranker rank1 代理值在 9/16 条为正，候选列表里最好的候选在 11/16 条为正；只看 rank2+ 候选时，2/16 条代理值为正。次级候选的 `p × 时延` 高于 rank1 的情况为 3/16 条。样本是诊断抽样且条件于实际发生恢复，且 shape 数据没有预热后图状态字段；这些计数不代表总体动作收益。

另一个两来源成本采样含 14 个 k=1 成本上下文、42 次重复；中位额外 shape 成本为 0.233ms。k=2 只有 2 个上下文、6 次重复。它记录了预热后的图状态，但只有 2 条同轮同时具备 P1 恢复时延与 k=1 shape 成本：第一条最高分备用 mass 为 0.03085，`p × recovery_ms` 为 0.114ms，shape 成本 0.131ms；第二条候选 mass 为零，shape 成本 0.287ms。两条的局部差值都小于零，样本不足以推断整体方向。成本采样另有 3 次 P1 与 1 次 P2 恢复记录在 220–246ms，字段没有给出足够原因，故保留原值并用中位数描述常见时延。

拟合报告的 206 个验证上下文里，同上下文实测 k=1 shape 成本覆盖为 0；可计算完整实测动作成本的上下文也是 0。拟合报告里基于预测 shape 成本与随机实现标签汇总的策略值不作为实测收益引用。

## 下一步次序

我建议先改进候选 mass/价值估计，并在来源留出中确认它能稳定改变 k=1 的候选 ID。数据中有真实的候选质量差异，尤其在 `p_main` 较低时；但当前 mass ridge 只比训练均值略好，value ridge 更差，同动作数下仍沿用 Ranker 候选。恢复时延主体又较稳定，复杂的恢复时延预测没有明显证据优先于候选 mass 估计。

动作池先保持 k=1。虽然部分次级候选能超过 ranker rank1，非诊断集里只有 41/250 条多候选上下文出现这种质量优势；k=2 与更大动作的成本数据也很稀。选择器回调 CPU 中位时长约 24.54µs，低于典型额外 shape 成本与 P1 恢复时长，但这只是单项量级比较。当前证据不足以把它认定为端到端瓶颈，也不足以把局部概率乘时延值报成整体收益。

最有价值的补充是同一前缀、同一目标分布下，对 ranker rank1 与指定次级候选分别记录多 seed 的 P1 命中概率，并同步测 k=1 action 的完整增量时长；保留来源留出。这样可以判断候选质量估计何时有用，再决定是否增加动作池。
