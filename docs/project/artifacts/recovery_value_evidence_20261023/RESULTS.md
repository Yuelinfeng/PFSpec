## 概率估计与真实成本

原八个训练来源产生2332个候选标签行，两个容量选择来源716行。四个预先列出的容量中，64棵深度2的树按来源等权备用概率均方误差选出。该指标从旧ridge的0.039218降到0.035144，降低约10.4%；纯Python与sklearn的716行预测最大差为0。池化备用误差为0.047967，与来源等权指标的权重不同。容量改善不能直接当作选择收益。

成本观察五个旧训练来源，共12个输入，33个真实状态、515个动作、1545次同步重复，覆盖读取长度128/256/512/1024。额外未命中路径中位费用约0.169/0.190/0.220/0.292毫秒；备用命中相对普通恢复节省约3.214/3.259/3.321/3.443毫秒。首次建图另列，温态重复期间没有新图事件。零/单备用使用同一合法强制miss token；该token的来源明确标注，未引入随机抽样。

成本只覆盖验证、提交和可选Target前向，未包含Ranker、MLP、概率构造、抽样及完整请求。因此结合真实概率得到的范围仍是操作代理，不能称为完整解码最优选择。成本汇总的n按三种常规提交长度重复计数，独立状态为33个。报告只使用中位数描述常见操作；原始异常值保留。

原数据分析见 `IDENTIFIABILITY.md`。772个非诊断可选状态中，首个备用的真实质量有600个为零；250个存在次级候选，其中41个次级候选质量更高。决策机会存在，但现有廉价特征尚未把它转化为稳定收益。

## 现有缺口与论文表述

独立概率审阅见 `INDEPENDENT_POLICY_REVIEW.md`。在两个容量选择来源的217个有备用轮次中，主候选真实概率均值约0.81571，预测约0.68346；容量选择只按备用误差，未共同优化主概率和动作收益。较小的备用均方误差伴随较弱的主概率校准，以及没有改善的候选身份选择。

线上策略没有单独预测EOS概率，把未建模的EOS质量计入未命中费用；保存模型的旧元数据写作common路径，与实际公式不符。builder文案已澄清为miss路径，没有重建或改动实测模型。原1908轮中一条EOS概率非零状态的同长度敏感度代入没有改变动作，仍不能保证其他状态不受影响。策略也没有为首次建图做独立价值决策。这些近似均保留，不能称为完整成本下的最优算法。

当前不足以启动新的来源外确认或声称完整请求收益。后续有价值的方向是验证更有信息的可用特征与决策收益目标，而非仅降低候选概率平均误差；需要同时处理主概率、错误候选选择及图准备费用。本文继续以已经实现的固定恢复预计算为主体，动态选择保留为有代码和实测边界的研究方向。
