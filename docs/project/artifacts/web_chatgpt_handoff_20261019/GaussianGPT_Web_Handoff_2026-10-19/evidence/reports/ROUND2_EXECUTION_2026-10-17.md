## 已取得的证据

448 个真实上下文中，现有 Medusa/Hydra P1 的固定前缀重合度为 1.566%/1.407%。位置 ID 与 rank 顺序一致；Hydra 训练和在线状态的归一化形式在已测范围内一致。训练、验证与真实域表现不同，条件不足和训练适配程度仍需分别分析。

额外处理历史 Feature 后，旧头的诊断重合度升至 63.647%/49.327%。该操作增加 Target 前向并改变旧头输入，不能解释成低成本草稿已经获得的加速。A2 改为直接读取历史 Feature embedding，进一步评价条件价值。

EAGLE 原权重保存为 FP32，训练 AMP 为 BF16。原八条轨迹、16,360 行在 FP32 下重算：完整 softmax 重合度约为 3.705%，top-p=0.9 后为 2.776%。P2F/F2P 表示隐藏状态转移，实际提案类型分别为 Position/Feature。

| 名称 | 历史输入 | 候选 Position | 输出方式 | 可训练参数 |

各方法共享同一 Ranker、K2 验证循环和历史信息。B1-E 的两 token 为已知历史 Feature 与候选 Position，推理不读取候选位置的未来 Target 状态。它是单步特征机制对照，未移植完整 EAGLE，也没有跨轮草稿 KV Cache。

训练复用相同 40 条 Target 轨迹、36/4 条完整轨迹划分，16,348/2,044 个训练/验证 Feature 行；10 轮、batch size 128、AdamW、学习率 1e-4、weight decay 0.01。首训练种子为 20261018。四种结构统一使用 temperature=0.9 的 Target 分布交叉熵，本轮未加入隐藏状态辅助损失。因此 B0 与旧同轨迹 MLP 的训练目标不同；旧 step12000 作为现用系统参照单独比较，不能把权重差异全归因于结构。

参数量与共享固定参数分别记录，没有要求四种模型凑成相同参数量。B1-E 读取的共享 embedding 和输出头不计入可训练参数，相关计算计入速度。结构比较仍受容量、参数化方式和有限训练预算影响。

在线设置为原十个开发来源、64/256/1024 可用前缀、两个运行种子、最多 256 新 token、FP32、temperature/top-p=0.9。Target、P-only、旧 PF 和四种新结构各 56 次，共 392 次；运行顺序轮换，加载和 warmup 不计时，缓存分配与前缀计算计时。训练种子与运行种子分别登记。

## K2 的计算解释

对本实现的普通轮次，提交 token 数为 2+2×I(P1 与 F1 均接受)。P2 未接受时仍会通过 Target 残差与补算完成下一对，因此提高 P2 接受率主要减少补算。考虑 EOS 后，提交量与 Target 调用数的逐条关系在全部 280 条 PF 记录中均一致。

旧 PF 平均每轮提交 2.603 token，B1-E 为 2.462，B0 为 2.293。旧 PF 的 P2 未接受数为 113，至多对应 5,875 次 Target 调用中的 1.92%；该比例还没有扣除 EOS 无需补算的情况，也不等于时间收益。

这给出后续工作的具体重点：Feature 的有效接受直接影响推进量；P2 条件化需要先抵消新增计算。接受率、参数量和实际速度分别报告。

## A2 结果与本批次选择

无需额外 Target 前向的历史 Feature embedding 对照未解决 P1 问题：448 个真实上下文中，状态单输入重合度为 1.610%，加入 Feature 后为 1.682%；更换历史 Feature ID 的诊断为 2.032%，没有表现出可靠的信息利用。三来源、单前缀的 12 次短测中，两种新 P1 路径的总体吞吐均低于 Target。训练预算、表示方式和来源变化仍未分开解释。

本批次保留旧 step12000 轻量 PF，不扩大独立 P1 模型，也未启动候选重排器、候选树或跨轮特征递归。B1-E 保留为机制研究候选；本轮数据不足以将其选作正式方案。因此尚未对新模型开展新来源正式比较或完整三维输出。
