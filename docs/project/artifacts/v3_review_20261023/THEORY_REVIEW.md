## 补充：σ(H) 的统计信息与可计算信息

蓝图行 125–135 将 I 定义为含完整已提交历史 H 的 σ-代数。对固定 Target 权重 θ、固定 tokenizer 与解码 mask，pθ(· | H) 是 H 的确定函数，因此对 σ(H) 可测；若 q 也由固定草稿模型及 H 确定，ρ 同样可测。若恢复时间 R 也由已给状态决定，则 E[ρR | I] = ρR，不会表达“要运行一次昂贵 Target 前向才能得到该数值”。若 R 还受未建模的设备噪声影响，条件期望只保留这部分不确定性，并不把 p 的前向计算成本编码进去。

因此要区分两种概念：

- **统计信息**：完整 H、固定模型参数和设备状态能否决定目标概率及恢复价值。固定 Target 下，目标概率已由 H 决定。
- **计算可得信息**：在线动作发生前，程序实际已经计算并允许使用的量，以及选择器的算力/查询时限。未运行 Target 前向时，p(b) 在计算上不可得；这不是它在 σ(H) 意义下不可测。

若要形式化 v3 的低成本选择器，应把在线输入写成 O=φ(H,K,Z,m,已缓存分数)，并明确策略类仅可读取 O、不得查询本轮 Target logits，或给出具体运行预算 τ。此时训练目标可写为 E[ρR | O]。如果策略仍可任意读取完整 H 并运行固定 Target，那么仅声明“决策前不可见”不足以构成信息论限制，需要转为计算预算/查询次数限制。

这也限定了蓝图行 202 的两世界遗憾例：同一 σ(H) 且固定 θ 时，两个不同 p 向量不可能对应完全相同的 H。若讨论不可辨识，应令两种不同历史 H_L ≠ H_H 被同一压缩特征 φ 映射成相同 O，并限定在线策略只能使用 O；或者明确模型/环境参数本身未知。否则行 202 的 0.04 下界只能视作人为设定的抽象决策问题。命题 1 行 183–200 的接受率反例则不受此问题影响：它只说明相同主接受率 α 不足以决定同一候选 b 是否值得加入，并不声称两种完整历史对任意计算器都不可区分。
