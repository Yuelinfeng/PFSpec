## 理论文本需要调整的核心

固定Target与完整历史H时，pθ(.|H)是H的确定函数，对σ(H)可测。因此E[ρR|I]中若I包含完整H，条件期望本身不能表示“未付费计算Target”。应写明在线输入O=φ(H,K,Z,m,已有评分)及允许的计算/查询预算，目标为E[ρR|O]；与ρR的差异来自表示压缩、未知量和受限计算。相同完整H与固定θ不能拥有不同Target概率；两个历史在压缩特征上相同才可支持该类不可辨识构造。

命题1需限定动作集为空或添加同一个b、其余条件核与成本固定。命题2还需提交后的KV/hidden与未来条件核一致。命题4需任意k子集可行且各候选收益不随集合改变。命题5的统一误差界没有从现有有限数据中获得；局部2δ不能表述成请求级保证。详见THEORY_REVIEW.md。

## 现在缺什么

完整解码记录没有保存逐轮可对齐的候选池、Ranker分数、Target备用概率、实际纠正位置、命中和恢复耗时。39个固定前缀保存的完整概率可做有限离线排序对照；它不能变成30来源在线逐轮数据，更不能从2908命中数反推出每轮概率。已有两前缀成本不能推广成任意上下文的可靠净效用标签。

主Position实际q=δa，Ranker分类分数需要另记t。三个近邻已有多分支、成本选树或廉价上下文估值；改变名称、增加备用数量、将t改成其单调函数都不能单独证明新的调度贡献。必须报告在同候选池、相同执行器和真实成本下，选择是否发生变化且是否产生实际净收益。
