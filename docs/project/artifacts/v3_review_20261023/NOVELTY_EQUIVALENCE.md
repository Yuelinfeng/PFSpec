## 两个容易产生虚假差异的地方

**实际抽样概率和Ranker分数必须分开记。** 当前主Position确定选a，所以采样中 qP=δa，所有其他候选的qP为0。Ranker的正类分数t(b)仍可排序，但它不等于该qP。把SpecBranch式7中的q直接替换成t，得到的是明确适配的置信策略，不能称原方法原样运行；把δa原样代入，则主置信为1且非主候选全并列，不能由这个退化输入宣称战胜SpecBranch。

**同样主接受率不等于同样完整候选接受信息。** v3两个世界只保持p(a)不变，b的Target质量明显不同。它说明一个标量不足，不说明Sequoia的整个接受向量或EAGLE-2的完整上下文评分都无法区分两个状态。当前复用机制中备用命中未计入主提案接受；通用树验证可能将类似分支记为接受，因此跨方法还应统一已提交token、实际Target工作与墙钟，不能只比较名为acceptance的字段。

## 可以直接判定等价的范围

对互斥备用，若R(b)=R恒定，实际额外成本仅依k，且廉价评分t与ρ严格同序，则按t与按ρR固定k选择相同。若进一步使用同一成本函数并枚举相同k，最优动作也相同。当前确定性主Position下ρ(b)=p(b)，故“残差排序”本身退化为按备用Target概率排序，并没有额外的概率变换贡献。

若预测值等于既有分数的单调变换，只提高拟合指标而没有改变选中集合或k，就没有新的调度效果。即使动作不同，也要在相同候选池、节点数/真实成本与同一执行器下证明更好；单次人为反例仅能证明可能不同。

## 合理的对照范围

先固定已有W1主采样和备用执行器，比较空集合、固定单备用、固定2/3/4备用、Ranker分数选择与拟议价值选择。前四项已有真实数据，不重新跑。将SpecBranch启发的规则和Sequoia启发的成本规则标明为适配；只有完整移植原方法并支付相同提案/设备成本时，才报告原方法名称下的速度比较。

k=1..4当前已有360次结果：增宽未带来稳定净收益。该负结果说明“更多覆盖”不能代替成本证据，也不自动排除按状态跳过或选择分支的价值。完整前向耗时、恢复耗时和选择器成本缺少逐轮可对齐标签时，不能训练后直接声称最优。
