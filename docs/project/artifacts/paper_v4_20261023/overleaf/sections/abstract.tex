\begin{abstract}
Autoregressive 3D Gaussian models construct scenes by alternating between spatial positions and discrete scene features, but token-by-token Transformer execution limits their efficiency. We present \PF, a speculative decoder that uses this Position--Feature (P/F) conditional structure to organize draft computation. A Position Ranker proposes legal spatial candidates from position history, while a conditional Feature MLP reuses an available target hidden state to predict the feature distribution at a candidate position. Together, they form a short P/F proposal path without maintaining a separate neural draft history cache; the target retains the full conditional history during parallel verification. Position Rescue further precomputes the conditional state of a backup position and reuses it when the original residual sampler selects that position, avoiding a serial recovery pass. We relate useful generation advance to recovery work and verification cost, and distinguish target-distribution preservation from trajectory preservation relative to a fixed reference decoder. On an RTX 4090, \PF\ achieves approximately $1.58\times$ decoding throughput over GaussianGPT with the same execution optimizations. Complete single-chunk requests capped at 512 new tokens achieve $4.31\times$ speedup over the original target implementation, including shared execution improvements and output-length differences. Completion and generation experiments ending at natural end-of-sequence (EOS) further demonstrate the utility of the basic P/F path for complete single-chunk 3D outputs.
\end{abstract}
