1. 核对主要不同方法的真实入口和已训练权重，保留未覆盖原因。优先EAGLE Feature/Joint、Medusa/Hydra、Ranker-only、Ranker+MLP、D8与LFQ等已有路线；同一结构的长训练节点不全部重复。

3. 先在三个开发场景、64/256前缀、一种子、256新token预算上同轮比较普通/优化两种执行。各方法单独持久runtime，首次构造、KV分配与图创建计入外层同步解码；独立预热runtime丢弃，权重加载单列。
4. 对主要方法在十个开发场景、64/256前缀、一种子、512新token预算上做同优化Target比较，顺序轮换。若排序发生可靠变化，使用独立来源确认领先者，不在确认来源上继续选参。
