## 与实际解码成本的区别

输入数据保留R1既有60次W1、每次最多64个新Token的运行和Profile。历史W1平均每轮Target主机时间20.278608毫秒、其他部分2.291834毫秒；这是R1旧运行的记录，不是本轮同一GPU时段复测。CPU筛选仅重算q、邻域和离线重合度，没有运行Target-only、W1或候选解码，也没有新采样轨迹。任何CPU毫秒/行均不可与上述历史单轮耗时直接拼接成加速比。

历史成本筛选仍依赖R1调用分布和此前1.7125倍速度参考，不是同轮成本测量。此次空间残差仅在两个留出来源上增加0.1084个百分点且落后于简单混合；该结果支持停止本轮，不构成实际速度或质量结论。
