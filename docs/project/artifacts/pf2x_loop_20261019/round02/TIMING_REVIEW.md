# Round02 Target 前向微测计时复核

## 结论

四 token 前向的配对 Host wall 比值中位数为 **0.995125**，对应分组实现的时长中位数约低 **0.49%**；CUDA event 比值中位数为 **0.995214**。两 token 和一 token 的 Host wall 中位数分别为 **1.005851** 和 **1.004082**，对应约慢 **0.59%** 和 **0.41%**。四 token 的全量算术平均比值为 **1.017796**，显示约慢 **1.78%**。

既定的 8% 短前向收益软阈值没有达到。结果只覆盖 Target 短前向的诊断计时，不能据此推算完整解码速度。当前数据不足以支持继续开发或增加独立测试。

本记录覆盖短 Target 前向；完整生成还包含分支调度、采样、KV 维护及变长停止等工作，当前结果不能直接外推到端到端速度。按既定阈值，本轮数据不支持继续投入开发或启动独立测试。
