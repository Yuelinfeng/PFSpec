β按首拒候选质量加权；有利事件另乘该分支自己Target给出的P2接受概率。两者是不同量。合法首拒触发率的格等权均值为52.7017%；本次两模式无不合法q2剩余支持，首拒质量加权不合法比例为0。分析使用实测P1接受率和P1接受条件下的Feature分布。a1=36.4396%是保存上下文的分布重合度均值，不能替代逐次实际Feature接受率。

两模式各48条真实分支，均覆盖20个来源前缀格；实际共有48个sample_id。两种q2的候选抽样种子不同，只有同上下文条件对应，不能把随机候选结果当作确定性配对效果或据此确认narrow优于wide。每格只有2至3个分支条件，来源区间仅重采样10个来源，没有包含上下文与分支抽样误差。

每模式配对16组，其中8组先2后4、8组先4后2，预热4次。总计4个模式×上下文组，实际仅2个唯一上下文、来自1个来源；两模式重复用了相同上下文；每个模式内部重复输入固定，但两模式的F2输入可不同。配对结果显示这些上下文2-token成本接近4-token，未提供调用次数减少的机制；不能外推到全部来源或完整生成。逐次CUDA event与主机时间分别保留，恢复成本在timing_restore_costs及原始日志中单列，两种时间不相加。

两模式合计Target调用648次：96次前缀、480次普通诊断形状、8次预热和64次配对形状。配对部分额外前向共72次、截短76次；全部诊断截短460次，不能将76写成总截短数。W1自身Target调用1811次，另有短重放18次；它们与648次诊断调用分列。

全部五阶段共193.622031秒，包含加载、短回放、采集、两模式分支、同步、写盘和CPU分析。原GPU已回到0%、2MiB。分阶段耗时和统一截止时间见budget.json；结果完整，未重试采集，没有新增训练。

本轮没有同轮Target-only，也没有新完整解码器。分析JSON的feasibility保持pending，原因是未提供同轮Target和W1实际性能对照。分布重合度、局部事件和形状时间均不能证明2×。有限样本中假定省去一轮Target且新增分支成本为0，只能得到乐观点估计，不能用作严格上界或停止研究的依据。
