开发矩阵为十来源、64/256 前缀、三个种子，比较原 Target、W1、备用 Position 与 Feature 分布复用。两个候选均完成后才评价，全部记录保留。

跨来源组使用 stage_e_final/final_test_crops.pt 中另外三十个来源，每来源取首个长度足够的裁剪。64/256 前缀，seed50101，512 新 token，FP32、temperature/top-p=.9/.9、容量2048。比较原 Target、W1、快速 Feature 混合、组合四臂，共240次，同轮轮换顺序，各臂持久图独立，首图成本计入。权重和混合比例不再用该组调整。若合法流、输出律或数值验证未通过，先解决具体原因再开始。

主倍率为组合/原 Target；新增收益为组合/W1；快速混合单臂用于区分接受改善与备用计算的贡献。报告三十来源等权几何平均倍率、按来源重采样95%区间，另报共同512-token、无新增图子集。接受率使用实际 Feature 接受/验证，备用 Position 命中单列。不同提案会改变随机轨迹，逐次相同输出只用于耦合实现对照。

这三十来源曾用于旧方法测试，本轮仅用于未在其上选取混合比例的新方法确认；不能称为全项目从未见过的数据。无新增三维解码与渲染计时，结果限于 token 解码。
