# 版本、结果与证据范围

## 选定算法

GGPT-W1-RESCUE-R1-20261025 指固定单备用 Position 的研究版本。主路径使用Ranker提出Position、轻量MLP提出Feature；W1采用四节点短树验证。备用从同次Ranker排序中取一个不同于主位置的合法非EOS位置。

正常轮五个输入是 `[F_prev, a, f, c, b]`，父节点为 `[-1,0,1,2,0]`，逻辑深度为 `[0,1,2,3,1]`。备用b和主位置a共享已提交历史及F_prev。主路径被拒绝后，参考残差抽样照常选择实际位置；只有抽中b才复用b行的Feature分布、hidden与KV，免去一次串行恢复。EOS、尾步和候选不足沿用原路径。

执行组成包括短块Target CUDA Graph、显式BMM注意力、按类型计算输出头、MLP提案图、RoPE准备和KV复用。固定方案不依赖动态价值选择，也不采用历史Feature分布混合。

## 定义与计时

解码倍率用每条实际生成token数除以同步外层耗时，先求同输入方法间吞吐比，再对来源内log比平均，最后跨来源等权取指数。区间以来源为重采样单位；四次重复没有变成120个独立来源。

解码计时包括运行时、KV、前缀、首次建图、提案、验证、抽样、恢复与状态维护；权重加载、VQ、渲染、文件保存排除。完整请求从就绪prompt到token、Gaussian NPZ及六张384×384 PNG保存完成；加载、独立预热、输入获取及结果JSON单列。4.307862为来源等权请求时间比，全量不同方法的输出长度不同；共同满512的19配对为4.185458。累计耗时比和来源等权比采用不同权重。

## 输出与计算量

首次确认W1/单备用60/60输出、长度、EOS及接受语义相同。Feature接受均为3701/10345。备用适用3875轮，主位置被拒858次，备用命中388次；恢复调用1181→793，Target调用12626→12238。额外3875树节点、3487输入token的费用已包含于净收益。

四进程480/480配对输出和接受语义相同，减少2908次恢复。有限GPU数值对照存在逐元素allclose未通过项；这些记录支持所测范围下的路径和分布接近，不能替代精确算术定理的前提。

完整请求W1/单备用20/20 token相同；60份NPZ、360张PNG的历史读取均有效。Gaussian行序及少量浮点像素有差异，不能写逐位相同，也不能推断绝对场景质量提高。包内保留output_audit.json，全部大产物仍在远端。

## 后续动态选择的实际状态

动态选择已经实现并测试，未证明稳定优于固定单备用或简单规则。2026-10-23最新开发验证包含33状态515动作1545重复、七方式两进程280条解码和12条逐轮诊断。价值策略/固定单备用0.993432 [0.990375,0.996144]；价值策略/零备用0.981747 [0.965543,0.997469]。备用概率均方误差改善约10.4%未转化为净选择收益。

此前20新来源的旧实现实验及后续实现维护结果也附入包中，便于识别不同版本。以上结果限定相应实现和测量范围，不能直接否定恢复价值研究方向。历史理论和v4文稿中把动态选择全部写成未来工作的段落已经过时，应结合这三份报告阅读。

## 论文边界

可主张：P/F条件链上的固定参考恢复复用实现、对应轨迹保持条件、恢复命中价值解释，以及所测范围内小幅可重复解码增量。主路径接受率不能充分决定指定恢复分支的启用决策。

尚未证明：相对SpecTr、Sequoia、SpecBranch的独立通用算法新颖性；有效动态预算分配；稳定新增完整请求收益；跨模型、跨硬件和任意长输出的普适优势。通用CUDA Graph、标准残差抽样及一般成本优化工具不宜作为首次理论贡献。
