# 提案分布与恢复计算的两个改动

输入是当前W1的同一Target、Ranker和MLP。需要同时回答两个问题：能否利用历史上已经算出的概率改善Feature提案；P1拒绝时，能否复用少量已经计算的备用结果。

## Feature混合的接受目标

在相同历史h、相同首位置a下，令p为当前Target的Feature policy，q为MLP提案，s为上一次实际位置处已获得的Target Feature policy。提案为qλ=(1−λ)q+λs。期望接受量为A(λ)=Σf min(pf,qλ,f)，也等于1减去p与qλ的总变差。

每一项是仿射函数与常数的较小值，因此A(λ)是分段线性的凹函数。该性质支持有限的混合诊断，但不保证任何非零λ都能提高接受量。s较陈旧或与当前条件差异大时也可能降低接受量；本轮39开发前缀已包含下降来源。不能在线读取尚未计算的当前p来选择本轮qλ。

在EOS概率为零、预算足够且采用W1正常树轮的简化情形，每轮期望输出为2+2·pP(a|h)·A(λ)。实际解码还包含EOS、K1尾部与不同历史，完整进展应直接用round_generated_lengths。跨来源平均pP与平均A不能随意相乘。

接受律min(1,pf/qλ,f)与拒绝后归一化(p−qλ)正部共同保持Target抽样分布。这是已有精确投机抽样规则的应用。复用对象是历史完整policy，而非未来标签，也没有更新Target或MLP权重。

## Position备用的成本条件

a为首候选、b为次高分备用候选。令α=pP(a|h)。α<1时，已经拒绝a的条件下，残差抽到b的概率为pP(b|h)/(1−α)；整轮中“拒绝a并抽到b”的联合概率为pP(b|h)。α=1时拒绝与备用命中概率均为零。预先计算b后Feature分布，实际抽到b时即可省去一次恢复前向。

该操作不改变首提案接受事件或正常轮输出量。净时间变化由额外树计算、备用命中时省去的恢复、缓存提交与图创建共同决定。不同轮次耗时与命中可能相关，不能把任意一批事件的中位数乘以另一批频率当作精确墙钟收益。

本轮将备用命中与原alpha接受分开计数，直接用逐请求同步外层时间测量其收益；同时记录增加的树节点和输入token。该记账可以区分“提案更容易接受”和“拒绝之后继续更省计算”。

## 可主张的范围

本项目新增的是这两个具体实现及其组合、对应数值验证与同轮实际测量。凹性、标准残差抽样、一般成本比值都不作为首次理论贡献。没有新的文献全面对照时，不宣称方法首次出现；有接受改善且有可信速度增量后，才将其描述为有效的新候选。最终证据见RESULTS.md。
