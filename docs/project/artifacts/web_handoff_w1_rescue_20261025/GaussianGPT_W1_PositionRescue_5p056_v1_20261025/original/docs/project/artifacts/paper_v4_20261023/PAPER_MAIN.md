## 1. 当前版本的定位

推荐题目：**Typed Proposals and Recovery Precomputation for Autoregressive 3D Generation**。

核心问题：在异质结构化自回归生成中，哪些条件计算值得提前执行，使它们在精确纠正抽样后仍可复用，且节约的串行工作足以抵消预计算开销？

当前实现回答一个具体子问题：保持原 W1 提案与抽样流程，在同一次 Target 验证中加入一个合法备用 Position，命中时复用其 Feature 分布、hidden 与 KV，省去一次串行恢复前向。当前没有得到可靠收益的动态价值选择器，也没有跨模型优势结论。

类型条件提案说明主路径的输入与条件依赖；恢复预计算承担现有方法机制；廉价信息驱动的集合选择已完成多轮空集/单备用的轻量实现验证，目前未得到强对照优势，作为研究边界。标准残差抽样、通用树验证、成本排序和统一误差界各自注明来源，不并列为原创贡献。

## 2. 模型与已实现方法

合法条件分布写作

\[
p(P,F\mid h)=p_P(P\mid h)p_F(F\mid h,P).
\]

EOS 不带后续 Feature。Target policy 包含实际类型约束、空间顺序约束、温度与 top-p。Ranker 的分类评分另记为 \(t\)，实际主 Position 提案为 \(q_P=\delta_a\)；不能把评分直接称为真实提案概率。

W1 的普通验证节点为 `[F0,a,f,c]`。单备用加入 `b` 后为 `[F0,a,f,c,b]`，父索引为 `[-1,0,1,2,0]`。备用节点只读公共前缀及 `F0`，提供历史 `(h,b)` 下的 Feature 输出与状态。它不参与额外的主候选接受测试。

主 Position 被拒绝后，沿用原残差分布及随机数抽取真实位置 \(Y\)。若 \(Y=b\)，提交备用路径并继续；否则沿用原串行恢复。EOS、尾轮及候选缺失沿用 W1。

固定提案、接受规则、残差抽样与随机数消耗顺序，在精确分支等价、正确逻辑位置及唯一 KV 提交的前提下，可以逐轮证明与 W1 的参考轨迹保持。GPU 有限精度与已测输出一致性分别报告，不由有限样本推出任意输入逐位等同。

## 3. 理论主线与完整前提

### 接受统计的决策不充分性

固定动作集合 \(\{\varnothing,\{b\}\}\)，主候选接受概率均为 0.7，备用质量分别为 0.02 和 0.20，额外成本均为 \(0.10R\)。备用的期望净节约分别为 \(-0.08R\) 和 \(+0.10R\)。其余条件与可替代恢复成本保持一致，最优动作相反。

这个反例表明单个接受统计不足以决定该动作。它没有证明已有通用树方法缺少相关信息。若进一步讨论廉价观测不可辨识，应使用不同完整历史 \(H_L\ne H_H\) 满足 \(\psi(H_L)=\psi(H_H)\)；固定 Target 下，同一完整历史决定同一 policy。

### 备用命中概率

令 \(\rho(b)=[p(b)-q(b)]_+\)。当集合 \(B\) 在草稿抽样前已固定时，

\[
\Pr(\text{reject},Y\in B\mid s)=\sum_{b\in B}\rho_s(b).
\]

当前点提案中，合法非主备用满足 \(\rho(b)=p_P(b\mid h)\)。条件于主拒绝的命中率还需除以 \(1-p_P(a\mid h)\)，分母为零单列。

若集合仅由状态及已抽草稿 \(X\) 决定，可按 \(X\) 的联合律求和。若还使用接受或残差抽样的随机量，须扩展联合条件，不能直接套用同一公式。

### 条件计算价值与实际开销

令 \(Z\) 是验证前已支付、允许读取的廉价信息，\(H_b\) 是原残差真实选中备用 \(b\) 的事件。定义

\[
m_b(Z)=\mathbb E[\mathbf1_{H_b}c_{\rm rec}\mid Z],\qquad
U(Z,B)=\sum_{b\in B}m_b(Z)-d(Z,B).
\]

\(d\) 计入额外节点、KV、图创建与复用、索引、选择器及执行交互的完整净开销，选择空集仍运行的选择器也要计时。选择器成本只计一次。将全部差异纳入后，这是成本记账等式；其预测能力需要独立数据支持。给定压缩 \(Z\) 后，概率与成本的条件均值通常不能直接相乘。

### 集合选择与信息限制

固定 \(k\) 的 top-k 结论需同时满足：恢复事件互斥；单项价值不随集合改变；成本只依赖 \(k\) 与 \(Z\)；**候选池中的任意 \(k\) 子集均可行**。组合约束存在时，应在合法小集合内求最大值，普通排序不保证最优。

例如权重为 10、9、1，但只允许集合 `{a,c}`、`{b,c}`；普通 top-2 `{a,b}` 不合法。仅有数量成本无法消除这一约束。

有限信息的最优期望效用不超过相同动作类下的完整信息最优值；统一效用误差 \(\delta\) 可导出局部 \(2\delta\) 选择损失。这些是标准决策工具，平均预测误差和来源重采样区间不提供该统一界。

Feature 加权 TV 分析保留 v4 D8 的固定外生状态分布与加权测度；不据此断言当前 MLP 已达到信息上限。局部效用也不自动导出完整请求最优，因为当前动作会改变后续图和缓存状态。

## 6. 正文结构与取舍

1. Introduction：P/F依赖、接受统计反例、恢复计算价值、固定参考机制、有限范围证据及贡献。
2. Related Work：精确抽样；树与预算及回滚；Gaussian/Mesh生成。明确 SpecTr、SpecInfer、Sequoia、SpecBranch 的重合。

4. Method：Ranker+MLP主路径与固定单备用。动态集合选择的本轮负结果移至讨论或附录。
5. Analysis：轨迹保持、命中概率和局部成本。Feature信息分析压缩篇幅，标准排序及误差结论注明归属。

7. Limitations：Target预训练来源未知、单设备/单模型、首次图、512上限、缺少公平通用树实测；本轮新20来源仅确认当前有限动作类。

## 7. 更新后的摘要工作稿

自回归三维生成按条件依赖交替输出位置与离散特征。主位置提案被精确纠正后，下一特征仍需要对应真实位置的 Target 条件状态。本文研究这类恢复计算的预计算价值，给出主接受率相同而最优备用动作相反的反例，并在 GaussianGPT 中实现固定参考的类型化恢复预计算：在同一次 Target 验证中计算合法备用位置的特征分布与缓存状态，真实恢复命中时复用；主提案、接受规则、残差抽样与随机数流程保持原样。在精确分支等价等前提下，该执行保持参考解码轨迹。30个既有来源上的四轮重复共960次解码、480个配对观测，输出与语义接受计数保持一致，减少2908次串行恢复，来源等权解码吞吐提高约1.81%，95%来源区间为1.48%至2.13%。更宽备用集合呈现边际收益下降。20新来源的两进程确认中，固定单备用解码吞吐提高约1.39%；完整请求按来源等权有约0.86%优势，但累计等待时间几乎不变、区间跨1。使用决策前廉价信息的动态价值选择未优于固定、概率成本及同数量排序对照。上述结果支持对条件恢复计算的受控复用与成本分析，同时限定当前动态分配与跨模型主张。
