# 类型化投机解码：理论草稿与证明范围

## 2026-10-23 论文主模型：固定抽样过程下的恢复预计算

本节是[论文大纲](PAPER_OUTLINE.md)的数学依据。既有W1和固定单备用已经实现；下述按收益选择集合的策略仅完成定义与推导，尚未接入解码或得到新的性能结果。标准残差抽样、条件期望、集合排序和误差界分别注明其作用，不将这些工具单独认定为新理论。论文价值须由具体问题差异、机制必要性和实证支撑。

### 1. 研究对象与目标分布

令h为完整已输出历史，合法下一token集合由类型状态τ与既有空间顺序规则给出。Target policy p_h是在合法性遮罩、温度与top-p之后的归一化分布。参考生成的有限长度分布为各步p_h的条件概率乘积，EOS与预算终止均包含在过程定义中。

P/F语法给出

\[
p(P_i,F_i\mid h)=p(P_i\mid h)\,p(F_i\mid h,P_i).
\]

这是条件分解。它不推出Feature在给定位置后独立于历史，也不推出相邻空间位置可交换。Ranker是位置历史的廉价近似；FeatureStateDraft输入前一Position的Target隐藏状态、前一Feature和当前候选Position，这些输入并非Target完整历史的充分统计量。其近似误差由已知投机接受与残差抽样处理。

参考解码器W1在完整语义状态s与随机流ξ下给出确定映射

\[
\Phi(s,\xi)=(o,s'),
\]

其中s包括输出历史、待消费Feature、逻辑KV、提案器在线状态、剩余预算和随机流位置。运行时另有g，保存图驻留、读桶、容量与设备资源。把语义状态与g分开只为说明哪些量保持；完整执行状态是(s,g)。

我们的预计算动作B只添加可能用到的Target条件状态。它保持主候选a、Feature真实提案q、接受规则、恢复抽样和随机数消耗顺序。目标是在这一受限策略类中降低完成同一参考生成过程的期望成本。

**整体优化定义。** 若把提案器θ与计算安排π同时视作设计变量，可写

\[
\min_{\theta,\pi}\ \mathbb E[T_{\theta,\pi}]
\quad\text{s.t.}\quad
\mathcal L(X_{\theta,\pi})=\mathcal L(X_{Target}),
\quad \operatorname{Access}(\theta,\pi)\subseteq\mathcal A,
\quad \operatorname{Resource}(\theta,\pi)\le\mathcal B.
\]

\mathcal A明确规定可读取的状态、特征与付费调用，\mathcal B规定候选节点、内存等资源上限；成本T包含全部获信与执行开销。随机数相同的逐路径保持仅适用于固定θ下的合法π，不是这整个可行类的约束。类型信息允许不同θ_P／θ_F，但不自动使它优于统一提案器。本节没有求解这一一般联合问题；后文分别研究固定状态分布下的提案匹配、固定θ下的恢复预计算。一般定义用于明确范围，不认定为新优化框架。

### 2. 可用信息与计算访问条件

时间顺序为：读取已提交状态 → 支付Ranker／可选提案成本 → 选定B → Target验证 → 接受或恢复抽样 → 提交真实路径。选择B时，当前验证才会产生的p_h不可免费使用。

这里必须区分两种限制。

**计算访问限制。** Target是已知确定性网络，h完整可见时，p_h数学上已经由h决定。“还没计算”不能被写成统计意义的不可测性。我们限定选择程序只调用已有廉价特征函数ψ与已支付的提案器，不在选择前额外运行Target；如果额外读取Target，新增调用及依赖成本必须计入动作。

**统计估计限制。** 为学习可部署策略，定义压缩特征Z=ψ(s,g)，如前缀长度、剩余预算、合法候选、Ranker得分与间隔、既有图状态。策略属于B=π(Z)，Z不包含本轮验证概率。研究状态分布μ上，不同完整状态可能有相同Z；条件期望E[·|Z]描述这些状态和参考抽样的不确定性。它不证明对任何使用完整h的程序都存在信息论下界。

候选集合C(Z)必须是互异、合法、非EOS位置且不含a。可以不完全覆盖Target支持集；集合外的实际恢复位置继续普通Target前向。Ranker的正类分数用来排序，未经校准不等于p_h或拒绝后的恢复概率。

### 3. 命题T1：相对固定参考过程的轨迹保持

**前提。** 精确算术，确定性Target；每个预计算分支使用与普通前向相同的逻辑历史、位置编码、合法性约束、logits／hidden／KV；未选分支不进入真实状态。B不改变参考随机操作，选择器若使用随机性须有独立随机流。图输出缓冲在覆盖前消费或复制。

**结论。** 对同一个(s,ξ)，任何合法B都实现同一Φ(s,ξ)，从而输出、接受事件、逻辑状态和参考随机流位置保持。迭代后，所有有限预算输出相同。结合参考W1的精确抽样性质，输出服从既定Target policy。

**证明。** 主接受分支完全沿用W1。主拒绝后残差分布及随机数相同，故恢复位置v相同。若v∈B，预计算的(h,v)条件状态与普通恢复相同；下一随机数抽取相同Feature并提交相同KV。若v∉B或为EOS，沿用普通路径。BOS与尾步沿用参考操作。逐轮归纳即可。

这是计算复用的正确性性质，比任意更换草稿后仍保持输出的Drafter-Invariant目标更窄。后者已有相关理论，见[正文研读](DOMAIN_PAPER_READING.md)。有限GPU同输出不能替代上述前提；现有BOS数值限制仍保留。

### 4. 命题T2：恢复收益的概率测度

给定完整状态与固定主点候选a，令H_b表示“a被拒绝且实际恢复位置为b”。若p_h(a)<1，

\[
r_h(b)=\frac{p_h(b)}{1-p_h(a)},\quad b\ne a,
\qquad \Pr(H_b\mid s)=p_h(b).
\]

**证明。** 拒绝概率1−p_h(a)乘以原残差r_h(b)。p_h(a)=1时所有备用质量为零，拒绝分布无需定义。EOS不进入B。全轮统计另乘适用轮指示，拒绝条件命中率不得与无条件命中率混用。

若一般提案q与B在草稿抽取前固定，标准接受规则的拒绝概率为ρ=Σ_v[p_h(v)−q(v)]_+，拒绝恢复位置b的无条件质量是

\[
\Pr(H_b\mid s)=[p_h(b)-q(b)]_+.
\]

这只是已知残差法的推论。B若依赖已抽取草稿Y，需条件于Y或显式对其联合分布求和，不能直接沿用固定集合公式。当前点提案是便于分析的特例。

### 5. 核心定义：每个候选值得预计算多少

令c_rec(s,b,ξ)为H_b发生时，可以替代的普通恢复前向成本，单位为时间；在H_b不发生的路径上取零扩展，使下式随机变量在所有路径上有定义。定义

\[
m_b(Z)=\mathbb E[\mathbf1_{H_b}\,c_{rec}(s,b,\xi)\mid Z].
\]

它是概率乘以事件条件成本的期望，具有时间量纲；该定义同时容纳不同位置的恢复成本、适用轮、EOS与状态差异。全状态成本在H_b内为确定值时，可写p_h(b)c_rec(s,b)。压缩Z下，E[p_h(b)c_rec|Z]一般不能拆成两个均值的乘积。

令D(s,g,B,ξ)为计算这些备用分支后，除被替代恢复前向外的全部净成本变化，包括额外节点、选择器、树组织、KV提交、图创建、内存访问和执行交互；d(Z,B)=E[D|Z]。则定义集合净收益

\[
F(Z,B)=\sum_{b\in B}m_b(Z)-d(Z,B),\qquad F(Z,\varnothing)=0.
\]

空集合采用参考W1且不支付额外选择器费用。如果某部署入口每轮先运行选择器再决定空集合，应将公共选择成本与所有动作比较，不能把空集合虚设为完全免费。

**成本分解命题。** 若上述成本组成覆盖所有实际变化，

\[
\mathbb E[C_B-C_0\mid Z]=-F(Z,B).
\]

证明直接来自逐路径等式C_B−C_0=D−Σ_b1(H_b)c_rec后取条件期望。收益事件H_b互斥，不能把多个备用命中当成同轮多次恢复节省。

定义D作为完整净变化可以使等式严谨，同时也可能使它只是成本记账。它的预测价值必须来自独立估计m与d后，能在未用于拟合的来源上预测动作优劣。共享设备交互无法独立识别时，应直接估计完整配对成本差，不能给回归分项附加因果解释。

### 6. 命题T3：受限等节点成本模型中的精确集合选择

**前提。** 在给定Z的合法集合C中，至多选择K个备用；完整额外期望成本仅取决于数量k，记d(Z,B)=d_k(Z)，d_0=0；m_b已知。这个假设包含候选准备与选择成本，排除节点身份导致的非同成本。图形状可按k变化，d_k无需线性或单调。

按m值降序排列b_(1),…,b_(M)，设S_k=Σ_{j=1}^k m_{b_(j)}，S_0=0。则

\[
k^*\in\arg\max_{0\le k\le\min(K,M)}\{S_k-d_k\},\qquad
B^*=\{b_{(1)},\ldots,b_{(k^*)}\}.
\]

**证明。** 对固定k，任一集合若包含较小m而漏掉较大m，交换二者保持d_k且不降低收益；因此前k项最优。再枚举合法k含0。

排序加扫描复杂度O(M log M+K)，候选和分数来自已有Ranker时不会新增Ranker调用，但成本仍包含评分／排序／维护与Target节点。此结论是标准交换论证，提供可执行的候选策略；它不证明Ranker原分数排序等于m排序，也不构成通用树优化新颖性。

若d_k−d_(k−1)非递减，则S_k−d_k的边际增益m_{b_(k)}−(d_k−d_(k−1))非递增，正边际前缀给出一个最优数量。若没有此条件，应枚举全部k；“遇到一次负边际立即停止”可能漏掉后续因图共享而出现的收益。

### 7. 命题T4：估计误差如何影响选择

对所有同一候选集合中的合法动作B，假设

\[
\sum_{b\in C}|\widehat m_b-m_b|\le\epsilon,
\qquad \sup_B|\widehat d(B)-d(B)|\le\delta.
\]

令\widehat F=Σ\widehat m−\widehat d，\widehat B为其精确最大值，B*为F最大值。则

\[
F(B^*)-F(\widehat B)\le2(\epsilon+\delta).
\]

**证明。** 任意B上|\widehat F(B)−F(B)|≤ε+δ。把差写为F(B*)−\widehat F(B*)，加\widehat F(B*)−\widehat F(\widehat B)≤0，再加\widehat F(\widehat B)−F(\widehat B)。若求解器只保证距\widehat F最大值η，则上界另加η。

若仅有逐候选误差ε_0且每集合至多K项，可将ε换成Kε_0。若\widehat F(\widehat B)>ε+δ，则该动作具有正真实局部期望收益。训练误差、平均MAE或来源区间都不自动满足这里的统一误差假设；取得数据依赖置信界还需明确样本分布、依赖关系和多动作覆盖。

本命题是标准近似决策的扰动界。它说明优先拟合最终收益排序与误差裕量，比孤立提高分类准确率更贴近目标。当前没有已校准的m／d模型或该误差界的实测认证。

### 8. 命题T5：什么时候局部选择能推到整请求

**受限条件。** 预计算动作保持每轮参考输出与语义状态，参考轮次边界也相同；动作不会改变后续图驻留、容量、并发、内存或其他成本状态；不存在跨轮总节点预算；有限token预算使总轮数有界。策略只依赖规定的Z，不依赖未来参考随机数。

在这些条件下，沿相同参考随机流的状态序列和结束轮次N对所有策略相同，

\[
\mathbb E[T_\pi-T_0]
=-\mathbb E\sum_{t=1}^{N}F(Z_t,\pi(Z_t)).
\]

逐Z最大化F的策略在这个受限类内最小化期望请求成本。

**证明。** 对相同参考轨迹逐轮相减并求和，利用指示t≤N的条件期望。由于动作不改变未来状态分布与可用动作，逐项最大化不会牺牲后续收益。

首次建图影响后续请求、容量受限的图驻留、动态选择改变随机轨迹或并发资源时，这个条件不成立。完整执行状态(s,g)必须进入已有有限期望成本框架：

\[
V(s,g)=\min_B\mathbb E[C_B+V(s',g')\mid s,g,B].
\]

这是标准动态规划，不将其写成新的全局调度理论。现有固定单备用含首次图创建，不能直接引用受限局部最优结论描述实际部署。

### 9. 四个必要反例

**接受率相同，恢复收益不同。** 主a概率均为.5；两个状态的p分别为(a:.5,b:.49,c:.01)和(a:.5,b:.01,c:.49)。主点提案接受率相同，预计算b的命中质量相差49倍。该例说明主接受率不足以决定恢复候选价值，不说明所有已有树目标无法表达它。

**压缩特征无法区分状态。** 两个等概率状态有相同Z，p分别为(a:.5,b:.5,c:0)和(a:.5,b:0,c:.5)；最多选一个备用，每节点成本.1、恢复成本1。知道完整p时每状态最优收益.4；只用Z的任意选择至多平均收益.15，差.25。该例是针对明确压缩特征的统计信息损失，无法证明对任意使用完整h的算法存在计算下界。

**图共享使简单边际停止失败。** m_(1)=.2、m_(2)=.19，d_1=.3、d_2=.31。第一个节点净收益−.1，两个合计+.08。枚举k发现收益；遇到首个负边际就停止会漏掉最优动作。

**局部成本不能代替未来成本。** 当前动作A成本1、动作B成本2；A引发下一轮额外成本100，B下一轮成本0。忽略g只选当前A会得到101，B得到2。数值为反例，不是本项目测量；它说明跨轮图状态必须进模型。

另一个精确性反例：在同一p=(.5,.5)下草稿固定给出token1，重复两次独立接受测试且任一次接受就输出1，会使输出1概率至少.75。增加候选后必须使用实际提案与有效选择规则。我们的备用只复用参考已经抽中的恢复位置，因此无需新增候选接受事件。

### 10. 有限精度与证据的关系

若每轮完整输出／状态转移核相对参考的总变差均有统一上界ε_t，标准逐步耦合可给有限轮轨迹差异≤Σ_t ε_t（至多1）。这一陈述要求整个转移核，包括提案、合法支持、抽样和状态更新；单行logits或policy诊断的TV不能直接代入。top-p排序临界点、BOS与跨桶状态可能需要单独分析。现有有限样本同输出只支持已测输入。

当前90个有理数用例及GPU数值记录属于实现证据，不替代一般证明。本轮追加纯CPU枚举用于寻找T2–T4推导的反例，结果位置将在主大纲记录；没有新增GPU测量。

### 11. 整体提案模型：压缩信息与有效推进

恢复集合研究保持W1抽样映射；Feature提案训练会改变W1映射，因此必须单独建模。两者仍可共用完整Target policy与真实生成成本，但不能用T1证明任意重训草稿后的同种子输出保持。

本小节采用理想化非终止模型：本轮可达Position policy的EOS质量为零，预算充足且可提出a与c。该前提不能由“观测轮中恰好没有EOS”替代；真实policy含EOS时，完整R须加入后文既有E1／E2项。令a是固定Ranker主位置，w(s)=p_h(a)，P_s(f)=p_h(f\mid h,a)，q_Z(f)是只读取压缩输入Z_F的Feature提案。参考接受规则给出

\[
\Pr(A_P\cap A_F\mid s)
=w(s)\sum_f\min(P_s(f),q_{Z_F}(f))
=w(s)\{1-\operatorname{TV}(P_s,q_{Z_F})\}.
\]

这里不假设Position与Feature接受独立；Feature接受是条件于主Position已接受、Target历史相同的概率。当前Feature草稿抽样与Position接受测试使用规定独立随机抽取。若提案还使用其他随机变量，应加入条件状态或对其积分。

正常轮生成量的期望为

\[
\mathbb E[R\mid s]=2+2w(s)\{1-\operatorname{TV}(P_s,q_{Z_F})\}.
\]

这是当前解码器的已有计数关系和标准总变差接受率的组合。它显示Feature误差的推进影响被主位置概率w加权；改善很少到达的条件与改善高w条件具有不同收益。EOS、尾步和候选缺失另计，成本可能也随q变化，因此该式不单独定义全局最优训练目标。

#### T6：给定压缩输入的最佳条件提案

当前实现的Z_F=ψ_F(s,a)至少包含前一Position的pre-finalnorm Target hidden、前一Feature与候选Position a，以及实际提案器读取的固定模型配置；不能省略a后仍称为同一MLP策略类。P_s明确记作部署policy p_F(·\mid h,a)，其下标仅标记完整状态。

为隔离提案表示能力，取外部规定、与本次q选择无关的评估状态分布μ，限定在上述正常轮中。q可以先由训练样本拟合，评价时条件于已经得到的训练结果；留出评估与训练内风险分开。本轮动作不改变所用μ。若改动q使真实轮次状态分布变为μ_q，应重新评价或保持单轮外生状态范围。令\bar w(z)=E[w(s)\mid Z_F=z]；当\bar w(z)>0，定义重加权状态分布ν_z为

\[
d\nu_z(s)=\frac{w(s)}{\bar w(z)}d\mu(s\mid Z_F=z).
\]

定义条件提案风险

\[
\mathcal R_z(q)=\mathbb E_{s\sim\nu_z}\operatorname{TV}(P_s,q).
\]

则只用z的提案中，最大化该条件平均联合接受等价于最小化\mathcal R_z。因Feature词表有限，q属于概率单纯形，连续凸风险存在最小值。有限加权状态标签下，这一问题为带单纯形约束的L1凸优化；它是标准统计决策问题，不是新抽样理论。

若\bar w(z)=0，Feature提案在这一正常轮群体中没有联合推进贡献，ν无需定义。神经网络的跨z参数共享、容量与输出top-p处理会进一步限制可实现q；单纯形最优仅提供表示层上界。

**证明。** 对联合接受表达取条件期望：E[w overlap\mid z]=\bar w(z)(1−\mathcal R_z(q))。\bar w不依赖所选q，因此两项目标等价。

#### T7：压缩输入造成的不可约匹配误差

令S,S'在给定z后独立取自ν_z，定义

\[
\mathcal D_z=\mathbb E\operatorname{TV}(P_S,P_{S'}),\qquad
\mathcal R_z^*=\min_q\mathcal R_z(q).
\]

则

\[
\frac12\mathcal D_z\le\mathcal R_z^*\le\mathcal D_z.
\]

**证明。** 总变差三角不等式给TV(P_S,P_S')≤TV(P_S,q)+TV(q,P_S')，取期望得下界。取q=\bar P_z=E_ν[P_S]，由L1凸性有TV(P_S,\bar P_z)≤E_S'[TV(P_S,P_S')]，再取期望得上界。

因此条件平均联合接受的最大值满足

\[
\bar w(z)(1-\mathcal D_z)
\le \max_q\mathbb E[w\,overlap\mid z]
\le \bar w(z)(1-\mathcal D_z/2).
\]

非零\mathcal D_z说明同一压缩输入下存在需要不同Feature分布的状态，即使优化达到单纯形最优也无法完全匹配。扩大网络但保持Z不变无法消除这一信息损失；增加输入信息可能降低最小风险，因为较细信息允许模拟原较粗策略。它不保证有限数据训练后的真实网络更好或成本更低。

实际MLP输入包含高维连续hidden，经验数据可能几乎没有完全相同Z。此时不能把人为分箱中的分布差异直接称为原输入的信息下界。估计\mathcal D_z需要明确的离散化研究模型、条件分布假设或受控状态构造。现有接受率与训后平台期未识别这一不可约误差，不能据此断言Feature草稿已经达到信息上限。

#### 训练目标为何需要分清

在同一ν_z加权状态分布下，完整teacher交叉熵在理想无限数据和无约束q下得到条件均值\bar P_z；匹配接受率对应上述TV风险，两个目标一般不同。若训练使用未按w加权的μ，CE得到E_μ[P_s\mid z]，还存在状态权重差异。例：ν_z以.8／.2取P_1=(1,0)、P_2=(0,1)。均值(.8,.2)的TV风险为.32；q=(1,0)风险为.2，且达到最小值。该例使用概率单纯形，不保证softmax有限参数精确实现边界分布，但可用极限逼近。

## 2026-10-22 恢复分支复用：正式算法与证明

本节针对已实测的单备用实现，线上入口为远端`gaussiangpt_spec_next_20261022/source_run02`。本机`patches/spec_next_20261022`后续扩宽实现的单备用路径与其相容。本节采用精确算术和确定性Target算子；GPU有限精度证据独立报告。标准接受与残差抽样沿用已有投机解码，本节贡献范围为保持原轨迹的恢复计算复用。

### 状态、输入与五节点布局

给定完整已输出历史`h=(…,P_prev,F_prev)`，Target KV只消费到`P_prev`，最后一个`F_prev`仍等待送入。状态还包含`P_prev`的pre-finalnorm隐藏状态、Ranker在线位置状态、剩余token预算，以及每臂独立的图与缓存对象。MLP据该隐藏状态、上一Feature和主位置a产生真实提案分布q。

正常树轮次需要至少4个剩余token且Ranker能够提出主位置a与后续位置c。从同一次Ranker排序取得一个不同于a的合法非EOS备用位置b；没有备用时沿用W1。五个Target输入为`[F_prev,a,f,c,b]`，父节点为`[-1,0,1,2,0]`，逻辑深度为`[0,1,2,3,1]`。节点4只看到共同前缀、节点0及自身，与主分支的a/f/c隔离。类型输出按P/F语法读取；b行给出真实历史`(h,b)`下的Feature logits和b隐藏状态。

树计算暂时写入物理KV槽位，验证后逻辑KV位置仍不变。只有实际选择的路径提交；节点4的KV在命中时移至连续位置。输出logits和hidden可借用图缓冲区，继续下一次同图验证前须消费或复制；新`h_prev`使用实际位置行的独立副本。备用未命中时，其状态不能进入在线历史。

### 算法：单备用恢复复用

```text
输入：历史h、等待Feature、主位置a、Feature提案q、后续位置c、备用b
1. 从实际q抽取Feature候选f；所有随机操作顺序沿用W1。
2. 验证五节点树，取得主Position policy p以及各分支的logits/hidden/KV。
3. 以p(a)执行原点提案接受事件。
4. 若a被拒绝，从原残差r(v)=p(v)/(1-p(a)), v≠a，抽取实际位置v。
   4a. v=EOS：只提交共同前缀节点[0]，输出EOS，结束。
   4b. v=b：提交[0,4]，从b行Feature policy抽取实际Feature，保存b行hidden。
   4c. 其他合法v：提交[0]，执行原Target恢复前向v，再抽Feature并保存hidden。
5. 若a被接受：执行原W1的Feature接受/残差以及后续Position处理，
   仅提交其真实路径；备用节点不改变这些接受事件。
6. 更新真实位置在线状态，令新Feature等待下一轮。
```

BOS起始、预算不足4、无法提出后续位置c和不存在合法备用均沿用原路径。备用不会接受EOS，也不会在主拒绝后再次进行候选接受测试。选b只依赖提案前已知历史和Ranker排序，不使用当前尚未计算的Target概率来筛选随机候选。

### 命题A：耦合轨迹保持

假设两算法从相同完整状态出发，使用相同主提案、实际q和随机数顺序；树注意力、逻辑位置与约束给出和普通Target恢复相同的条件logits、hidden及KV；提交后未选择节点无法影响后续计算。则单备用与W1逐轮产生相同输出，并进入相同真实生成状态。

证明：主提案、Feature抽样和主Position接受事件相同。主接受时沿用同一后续W1操作；主拒绝时残差r相同，因此恢复位置v相同。v=EOS时两者同样结束；v≠b时两者执行同一普通恢复；v=b时树分支拥有相同逻辑前缀`(h,b)`，其Feature分布、hidden、KV等于普通恢复计算，故用下一随机数抽得相同Feature，提交后状态相同。尾步与BOS沿用相同路径。对轮次归纳可得全部有限预算输出相同。

该命题直接证明对W1的轨迹保持；结合W1在精确算术下的标准分布保持结论，可得与原Target参考policy同分布。相同seed的普通Target与投机实现使用不同随机调用次序，二者无须逐token相同。浮点中的算子重排、支持集变化和KV误差可能破坏命题前提，有限样本同输出与数值容差只支持所测实现范围。

### 命题B：命中概率质量

在一个适用轮次中条件于全部提案前信息（主a和备用集合B已确定），令p为采用既有约束、temperature/top-p后的Target Position policy。若p(a)<1，

\[
\Pr(v\in B\mid a\text{拒绝},h)
=\frac{\sum_{b\in B}p(b)}{1-p(a)},
\qquad
\Pr(a\text{拒绝且}v\in B\mid h)=\sum_{b\in B}p(b).
\]

证明：点提案拒绝概率为`1-p(a)`，拒绝后分布r在a外为`p/(1-p(a))`，直接乘法和求和即可。B包含互异合法非EOS位置且不含a。若p(a)=1，拒绝和备用质量均为0，无需计算零分母。统计全轮命中还需乘适用轮次指示变量；858拒绝与388命中的条件比例不能当作所有轮次的命中概率。Ranker分数用于选择B，不能替代公式中的Target质量。

### 命题C：局部成本条件

在同一状态及同一耦合随机轨迹中，定义H_b为主拒绝且恢复位置为b的事件。C0是W1一轮总成本，CB是备用一轮总成本，c_rec(h,b,ξ)是命中事件中省下的实际恢复前向成本。若可以将其他改动全部记入额外成本D_B(h,ξ)，有

\[
\mathbb E[C_B-C_0\mid h]
=\mathbb E[D_B\mid h]
-\sum_{b\in B}p(b)\,
\mathbb E[c_{rec}(h,b,\xi)\mid h,H_b].
\]

D_B包括新增Target节点、树索引、非连续KV提交、图创建以及额外执行状态开销；不能只计Ranker的候选排序。恢复成本若在该状态对其他随机量不变，条件均值可写为c_rec(h,b)。零概率事件对应项为0，不求其条件均值。第k个备用的局部收益要求其新增省时质量超过额外期望成本；有限候选下边际命中可迅速降低。任意权重的Ranker排序不保证按此成本目标最优。

路径计算和共享设备存在交互时，D_B须包含这些交互，公式才是完整分解；若仅以孤立微测近似D_B和c_rec，它只是预测模型。图驻留改变未来轮次、长前缀与显存行为时，不能从一轮公式推出完整请求最优性。当前实现保持固定单备用，没有有效在线预算选择的主张。

## 1. 问题与状态

场景序列为 `P1,F1,P2,F2,…,EOS`。给定已完成的前缀 h，Target 的下一 token 分布记作 p_h，包含既有合法位置规则、temperature 与 top-p。参考过程使用相同规则。本文不改变 Target 权重或其条件分布。

生成状态可以写为

\[
s=(h,\tau,K,d,g,n),
\]

其中 τ 表示下一 token 类型，K 为 Target 已消费前缀的 KV，d 为提案所需状态，g 为已创建图、缓存容量和设备执行状态，n 为剩余预算。使用完整历史 h 定义状态，不假设 MLP 输入是 Target 的充分统计量。

Position 合法集合由递增的空间序号与 EOS 组成，Feature 合法集合为已有 4096 个码。P/F 类型构成简单的状态转移：P→F→P，EOS 在允许的位置终止。该类型描述只表达已有语法；没有新增空间对称性或生成独立性假设。

提案采用两种分布：

\[
q_P(v\mid h)=\delta_{r(\psi_P(h))}(v),\qquad
q_F(v\mid h,p)=q_\theta(v\mid\phi_F(h),p).
\]

r 是已有 Position Ranker，ψ_P 是其在线位置状态；φ_F 包括 MLP 实际使用的前一 Position 隐藏状态与前一 Feature。Target 仍按完整前缀给出 p_h。压缩提案输入的误差由拒绝采样处理，不能由这个记号推出信息无损压缩。

## 2. 命题一：混合提案的分布保持

**前提。** 对固定历史 h，p、q 均为已知且归一化的有限离散分布。从 q 抽取 y，并以 `min(1,p(y)/q(y))` 接受。只在 q(y)>0 的抽样点计算比值；拒绝后从归一化的 `[p-q]_+` 抽样。

**结论。** 最终下一 token 服从 p。这个性质允许不同 token 类型使用不同提案，也允许合法历史上的提案选择依赖过去信息。

**证明。** 候选在 v 处被接受的概率质量为 `min(p(v),q(v))`。令

\[
A=\sum_v\min(p(v),q(v)).
\]

若 A<1，拒绝后的分布为

\[
r(v)=\frac{[p(v)-q(v)]_+}{1-A}.
\]

于是输出质量为

\[
\min(p(v),q(v))+(1-A)r(v)
=\min(p(v),q(v))+[p(v)-q(v)]_+=p(v).
\]

若 A=1，则 p=q，拒绝事件概率为零，不计算零分母残差。对点提案 `q=δ_y`，接受概率为 p(y)，拒绝后移除 y 的概率质量；这是同一公式的特例。

沿合法历史逐步应用该结论，并要求每次 Target 概率对应真实已接受路径，可用条件概率连乘证明整条有限预算序列与参考过程同分布。自适应选择提案时，必须在扩充后的已知状态下使用实际提案分布；若先观察候选再筛选，却仍使用筛选前的 q，上述证明不适用。

**贡献位置。** 这是标准投机抽样在异构 P/F 提案上的实例化。W1 的应用无需新的抽样法。W2 涉及逐次无放回候选和变化的残差分布，需单列其对应条件分布证明，不能直接把本节的一步证明作为所有树验证的保证。

**实现边界。** 既有真实前缀数值对照的最大 policy TV 为 1.15744e-6，支持集差异为零；440 项逐元素 allclose 诊断仍保留。纯 BOS 另有不满足既定数值范围的历史记录。因此“精确算术下分布保持”与“任意输入的浮点实现完全相同”是两种主张。

## 3. 命题二：P/F 正常轮次的提交量

**前提。** 使用当前 W1 或相同 pair 恢复规则的 W2，剩余预算至少四 token，Ranker 能提供 P1/P2，本轮没有 EOS。令 A1 表示 P1 接受，AF 表示至少一个 F1 候选通过逐次验证，A2 表示相应 P2 接受。

| 实际路径 | 本轮提交 | 额外 Target 恢复 |
|---|---:|---|
| P1 拒绝，抽取真实 P1 后生成 F1 | 2 | 恢复真实 P1 的前向 |
| P1 接受，F1 候选全部拒绝 | 2 | 本轮无需该类恢复前向 |
| P1/F1 接受，P2 拒绝后生成真实 P2/F2 | 4 | 恢复真实 P2 的前向 |
| P1/F1/P2 全接受，再抽取 F2 | 4 | 无 |

因此，在上述非终止路径上恒有

\[
R=2+2\mathbf1_{A_1\cap A_F}.
\]

若局部模型将 EOS 概率设为零，则 `E[R|s,w]=2+2a_w(s)`，其中 `a_w(s)=Pr(A1∩AF|s,w)`。也可按条件概率链写为 `Pr(A1|s,w)Pr(AF|A1,s,w)`；这不要求两个事件独立。不同轮次混合得到的总体接受率不能直接代入状态条件公式。仅仅观察到一次请求没有 EOS，不足以将原模型的 EOS 概率视作零。

**证明。** 表中四种路径互斥且覆盖前提内的轮次，分别代入指示变量即可。P2 接受影响恢复成本，未改变这些轮次的提交量。

这个结论把实际提交量与“连续接受了几个候选”区分开来。EOS、末尾预算和没有位置候选的路径使用独立项；它们不满足本命题的四 token 前提。

**EOS 推广。** 本轮开始预算至少四 token，P1/P2 均有合法非 EOS 候选时，定义 E1 为 P1 被拒后从残差抽到 EOS；E2 为 P1 与 Feature 接受、P2 被拒后从残差抽到 EOS。AF 在 A1 未发生时按 false 处理。E1/E2 互斥，EOS 计为一个生成 token。两种终止路径分别提交一个、三个 token，因此

\[
R=2+2\mathbf1_{A_1\cap A_F}-\mathbf1_{E_1}-\mathbf1_{E_2},
\quad
\mathbb E[R\mid s,w]=2+2a_w(s)-e_w(s),
\]

其中 `e_w=Pr(E1∪E2|s,w)`。预算不足、候选缺失进入 K1、BOS 起始处理仍单列，不能用这个推广代替所有路径。

## 4. 命题三：恢复成本与增宽条件

先在不含 EOS 的局部模型中，对同一个状态 s、相同正常轮次规则，定义平均总成本

\[
c_w(s)=b_w(s)+\mathbb E[
 \mathbf1_{\neg A_1}C_{\mathrm{rec},1}
 +\mathbf1_{A_1\cap A_F\cap\neg A_2}C_{\mathrm{rec},2}
 \mid s,w].
\]

b_w 收录 Ranker、MLP、Target 验证、图准备、采样、状态维护和 KV 提交等全部非恢复成本。分支成本可随上下文和随机路径变化，故保留指示变量与成本的联合期望。

局部平均推进效率记为

\[
g_w(s)=\frac{2+2a_w(s)}{c_w(s)}.
\]

若从 w 扩宽到 w'，且 `c_w>0`、`c_w'=c_w+Δc>0`，令 `Δa=a_w'-a_w`，则

\[
g_{w'}(s)>g_w(s)
\iff
\Delta a>\frac{1+a_w(s)}{c_w(s)}\Delta c.
\]

**证明。** 将两个正分母交叉相乘并展开即可。它精确表达“增加的有效提交收益要覆盖增加的成本”。若恢复节省使 Δc 为负，也应使用实际总成本代入，不预设扩宽一定更贵。

这是局部设计引理。它没有证明逐状态贪心选择在整条序列上全局最优，因为动作会改变运行状态和后续轮次分组。它也不等价于用一次接受率统计拟合出最优宽度。

对原模型的 EOS 推广，P1 与 P2 恢复项分别使用 `¬A1∩¬E1` 和 `A1∩AF∩¬A2∩¬E2`，因为 EOS 后不再运行恢复前向。令 `r_w=2+2a_w-e_w`，增宽条件为

\[
c_w(2\Delta a-\Delta e)>(2+2a_w-e_w)\Delta c.
\]

不含 EOS 的阈值只是 `e_w=Δe=0` 的特例。

## 5. 有限请求的整体模型

给定请求初始状态 s0，策略 π 选择提案方式和验证预算，定义

\[
J(\pi)=\mathbb E_\pi\left[\sum_{t=0}^{T-1}C(s_t,a_t)+B(h_T,g_T)\right].
\]

B 包含最终 VQ、Gaussian 导出、渲染与图片保存成本。EOS 或预算耗尽时停止；g 保留首次建图、图复用和设备资源对耗时的影响。

在成本可加、状态充分描述执行条件且期望有限时，相应最小期望时间满足标准动态规划形式

\[
V(s)=\min_{a\in\mathcal A(s)}
 \mathbb E[C(s,a)+V(s')\mid s,a],
\]

终点取 `V(s_T)=B(h_T,g_T)`。这是设计问题的数学表达，当前实现没有求解这个完整方程，也没有全局最优保证。完整历史和设备状态使其空间很大；实践中的低成本预测或分桶表只能作为近似决策工具。

对固定 token 工作量，可另报告实际 `ΣR/ΣC`。不能把 `E[R/C]`、`E[R]/E[C]`、逐来源几何平均和自然结束的请求时间比当作同一个量。
