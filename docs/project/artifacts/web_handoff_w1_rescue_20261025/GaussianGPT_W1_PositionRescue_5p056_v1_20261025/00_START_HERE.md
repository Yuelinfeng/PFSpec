## 先读什么

1. `02_VERSION_AND_RESULTS.md`：算法版本、各项倍率、验证结论及限制。

3. `01_FOR_WEB_CHATGPT.md`：可直接粘贴给网页版 ChatGPT 的阅读请求。
4. 根据具体问题，通过 `04_FILE_INDEX.csv` 定位原件，再读取 `original/` 中的代码或数据。
5. `05_PACKAGE_VALIDATION.json` 记录本次压缩包整理时的 CPU 核验。

## 原件与当前说明的关系

`original/` 保留来源文件的原有字节与相对目录。历史文稿中的“下一步”“尚未实现”等表述只反映写作当时；当前状态以本包根目录的说明及2026-10-23三份动态选择报告为准。原件中的建议和命令供审阅参考，不代表本次要求启动训练或实验。

包内有当前本地推理源码、历史数值验证、逐请求token与耗时、重复记录和统计结果。包内没有完整远端主工程、模型权重、原始场景数据及全部三维大产物。它可以用于研究审阅和 CPU 数据复算，无法直接在无 GPU、无运行资产的环境中复现推理。

本地源码后来增加了备用数量1–4的支持。首次5.056076×的精确实测入口仍是远端 `source_run02`；本包没有新取得该目录的独立副本，历史逐文件比对记录只证明当时的对应关系。详见版本说明。
