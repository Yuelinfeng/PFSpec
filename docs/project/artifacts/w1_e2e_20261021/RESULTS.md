## 测量边界

RTX 4090、PyTorch 2.8.0+cu129、FP32 highest、TF32 关闭、batch=1、temperature/top-p=.9/.9，沿用已有 Target、Ranker、step12000 MLP 和 VQ 权重。实际 W1 源码为远端 `gaussiangpt_feature_tree_20261021/source_run04/`。

一次请求从已就绪的 token 前缀开始，到保存 token、压缩 Gaussian NPZ 与六张 384×384 PNG 结束。计时包含运行时创建、KV 分配、首次建图、前缀计算、候选提案、验证、恢复、抽样、序列验证、VQ 解码、参数转换、渲染和文件保存。GPU 在请求起止及阶段之间同步。

权重加载 11.218735 秒、预热 3.886902 秒均单列。预热图对象丢弃；每组使用一个新的 W1 运行时，正式请求间复用图，首次创建成本进入主结果。输入读取和结果 JSON 写入在计时外。本轮覆盖单个局部 chunk，输入已经是 token 前缀，未测原始场景编码、多 chunk 拼接或进程启动到首张图片的速度。

## 512-token 组的阶段开销

| 平均每请求，秒 | 原 Target | W1 |
|---|---:|---:|
| token 生成及运行时建立 | 7.197241 | 1.517663 |
| 序列验证、打包和 token 保存 | 0.001724 | 0.001473 |
| VQ 解码及 Gaussian 参数转换 | 0.056172 | 0.055510 |
| Gaussian NPZ 压缩保存 | 0.130945 | 0.125246 |
| 六视角渲染 | 0.001504 | 0.001534 |
| 六张 PNG 保存 | 0.057255 | 0.053818 |
| **端到端合计** | **7.444841** | **1.755243** |

同一轮 token 生成来源等权倍率为 4.874125×，端到端为 4.334555×。后续阶段每次为 W1 增加平均约 0.238 秒。此前 4.966189× 来自另一轮 token 测量；本轮输入与输出重放一致，计时存在轮间变化。不能把两个轮次的差值全部算作 VQ 与渲染成本。

只去掉 Gaussian NPZ 与 PNG 保存时，来源等权倍率为 4.723533×；该值仍包含 token 保存等操作，主结论采用完整保存后的 4.334555×。
