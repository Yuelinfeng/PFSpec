# 单步 Feature Transformer 接入与三种子续训

日期：2026-10-28。状态：实现、六组续训、所选模型验证、14 组解码对照与 420 次在线比较均已完成。

## 目标与已有依据

用户要求尝试实现单步 Transformer，依据为此前同预算三种子 B1-E/B0 对照。旧结构比较使用 40 条轨迹、36/4 划分、16348/2044 行、10 轮训练。B1-E 相对 B0 的吞吐点值为 1.064、1.046、1.016，三个区间仅一个不含 1；在线 Feature 接受率分别为 28.30/28.61/27.22%，B0 为 21.87/23.53/19.96%。依据为 `artifacts/pf_comparison_20261025/mechanism_run01/records.jsonl` 与同目录报告。

本轮沿用原结构及三个种子各自所选权重，在当前完整 Feature 数据上等量继续训练，与同种子 MLP 配对。原 step12000 单独作为现用模型参考，不能把其不同训练历史归为纯结构差异。

## 实现

输入为上一 Position 的 Target 最终归一化前状态、上一已提交 Feature 与当前候选 Position。两个 token 使用原 Target embedding，经 1024→256 压缩；Target 状态经 LayerNorm 和 1024→256 压缩后加到两个 token，另加角色 embedding。

一层 Transformer，宽度 256、4 个注意力头、FFN 512、GELU、pre-norm、dropout=0。因果遮罩使上一 Feature 不读取后一个 Position，Position 可读取两者。最后一个 token 经 256→1024 输出层，加回输入 Target 状态，再经过 RMSNorm、固定 Feature 输出权重与 15*tanh(logits/15)。可训练参数 1,317,632；固定 token embedding 与 Feature 输出权重共 16,646,144 个元素。不维护跨轮 Draft KV。在线复用现有 `MLPAdapter` 与通用提案图接口，实际网络由所载入权重及 `architecture` 字段确定；图统计中的 `graph_forward_mlp` 是该接口沿用的计数名称。

固定遮罩在创建模型时分配，不在前向中新建。在线模型直接引用 Target 的 GPU 权重张量，并核对存储地址，Feature 输出权重和 token embedding 均无需额外副本。普通前向、CUDA Graph 与原 B1-E 输出做对照。Target 的 embedding 和 Feature 输出权重从原始 GPT 权重读取，Feature 输出权重与先前推理环境的固定权重逐元素相同。

## 训练与评价设置

种子为 20261018、20261019、20261020，各含 MLP 与 Transformer 两组。旧权重来自同种子原 B0/B1-E 的 selected.pt；旧搜索均执行 10 轮，所选轮数依验证重合度而异。

继续训练沿用当前 400/50 条完整轨迹划分，共 418,021/46,893 个 Feature 行。每组新增 1200 次更新、每步两条轨迹、256 行分块；同种子两组的轨迹顺序相同。新增样本呈现 2,508,126 行，即训练集六遍。损失为原始 Target 完整分布交叉熵加 2 倍策略 TV，AdamW，学习率 1e-4 余弦降至 1e-5，权重衰减 0.01，梯度范数上限 1。BF16 训练、FP32 验证，TF32 关闭；每 400 步在完整验证集选择模型，初始权重也参与选择。

训练结束后对所选 Transformer 再做原/新前向、图执行及因果对照：扰动后一个 token 的交替维度，要求首 token 不变；去掉遮罩后要求该扰动能够改变首 token。随后使用相同 W1 解码与 Ranker，先完成七配置、两个前缀的普通/图输出与动作对照，再运行 30 来源、64/256 前缀、seed57101、512 新 token 上限，共 420 次。接受率为接受 Feature 数除以实际验证数，另保留接受数除以提出数。训练种子不当作新的独立来源；跨种子统计保留同一来源内所有种子与前缀。

单独测量 batch1 图前向耗时，并报告完整解码吞吐。没有多 chunk、VQ 解码或三维质量评价；原 step12000 与生产入口保留。

## 完整验证集结果

每组均运行 1200 步；按完整验证集选择的步数可不同，旧权重也参与选择。相同新增更新数结束时的数值另行保留，避免把模型选择与训练预算混为一谈。

| 训练种子 | MLP 所选步数 | MLP 重合度 | Transformer 所选步数 | Transformer 重合度 |
|---|---:|---:|---:|---:|
| 20261018 | 800 | 11.7382% | 800 | 14.3656% |
| 20261019 | 800 | 11.0841% | 800 | 14.6432% |
| 20261020 | 800 | 11.1752% | 1200 | 14.2484% |

该结果来自相同验证上下文的分布重合度。两种结构均低于现用 step12000 的 26.7549%；后者经历了不同的预训练与更长训练，不能用于单独判断结构差异。在线结果完成前不替换默认模型。

三组统一取最后第 1200 步时，MLP 与 Transformer 的验证重合度分别为：

| 种子 | MLP 第1200步 | Transformer 第1200步 |
|---|---:|---:|
| 20261018 | 11.1017% | 14.0240% |
| 20261019 | 10.7898% | 14.3070% |
| 20261020 | 11.1222% | 14.2484% |

因此验证重合度的方向在统一更新步数下保持相同。在线比较仍使用各自按完整验证集选出的权重，原始阶段记录均保留。

## 在线结果

七个配置各 60 次请求，共 420 次，均完成。两种同预算结构使用相同 W1、Ranker、Target、采样与图执行框架。Feature 接受率按接受数除以实际验证数统计。

| 训练种子 | MLP 接受/验证 | MLP 接受率 | Transformer 接受/验证 | Transformer 接受率 | 接受率差，百分点 [95%来源区间] | Transformer/MLP 吞吐 [95%来源区间] |
|---|---:|---:|---:|---:|---|---|
| 20261018 | 2846/10962 | 25.9624% | 3069/10594 | 28.9692% | +3.0068 [0.6892, 5.3881] | 0.976121 [0.898880, 1.026809] |
| 20261019 | 2816/11123 | 25.3169% | 3164/11008 | 28.7427% | +3.4258 [1.1652, 5.6569] | 1.028980 [1.011626, 1.048282] |
| 20261020 | 2730/11144 | 24.4975% | 2906/10886 | 26.6948% | +2.1973 [-0.4413, 4.7669] | 1.041372 [0.990055, 1.129731] |

在每个来源内保留三种子与两个前缀、先平均配对 log 吞吐比，再跨 30 来源等权，合并倍率为 1.015092 [1.002824, 1.028128]。区间以来源重采样，不把三种子当作 90 个独立来源，也不代表对训练种子总体的推断。

三个种子的 Feature 接受率点值均增加，前两个差值区间为正，第三个包含零；速度点值两正一负，单个种子中仅 20261019 的区间不含 1。当前支持这个单步结构在本轮同预算对照下改善接受率，不支持每个训练种子都更快的结论。

现用 step12000 MLP 在同轮接受率为 3588/10222=35.1008%，汇总吞吐为 353.334 token/s。三个 Transformer 相对现用 MLP 的来源等权吞吐比分别为 0.931522 [0.858954,0.981752]、0.979101 [0.951850,1.006094]、0.949906 [0.928676,0.971224]。因此仍保留 step12000 为默认模型。它具有不同预训练和更长训练历史，以上仅为当前实际模型的比较。

## 执行成本与首个种子的解释

MLP 的 batch1 FP32 图前向中位数为 64.84–65.13 μs，Transformer 为 74.02–74.20 μs。测量含输入复制及可能的 CPU 发起间隔，排除策略变换、抽样与 Target；完整请求成本还包括前缀、首次建图、验证、恢复和状态维护。

20261018 的来源等权速度点值低于 1，而汇总 token/s 高于对应 MLP；两者权重不同。最明显的来源为 `1af21af5-a873-492c-b201-c8d3eb4888b4`：

- 前缀 64：MLP 生成满 512 token，3.5312 秒；Transformer 生成 21 token 后 EOS，0.7582 秒，两者均从零建图。
- 前缀 256：两者均生成 512 token；MLP 2.0114 秒，Transformer 3.0007 秒。Transformer 前次短输出只建立了较短上下文的图，这次从 1 个补到 4 个；MLP 从 4 个补到 5 个。
- 该来源吞吐比为 0.357840。仅作为诊断，移除首个来源后该种子点值为 1.010490；正式结论仍包含所有 30 来源，不用该子集替代主结果。

已核对配置、数据对齐、实际加载的结构与参数、图回放、输出长度和首次建图安排。新旧网络定义在相同所选权重下输出相同；接受规则及 W1 状态处理没有重写。低于预期的速度点值包含不同终止长度与图创建成本，不能直接解释为注意力结构没有作用。

## 验证与操作对象

- 三种子原 B1-E/新定义前向逐元素相同，图前向与普通前向相同；所选新权重再验证通过。
- 对后 token 的交替维度施加扰动，遮罩下首 token 不变，移除遮罩后首 token 改变，三组均通过。
- 六个模型两步训练完成，正式六组均新增 1200 次更新和 2,508,126 行样本呈现；固定第1200步的验证方向也一致。

- 所选权重元数据、网络结构和可训练参数对应：MLP 2,864,384，Transformer 1,317,632；两者参数量没有刻意匹配。
- Transformer 三组提案图实际回放 11,525 / 11,898 / 11,910 次，均无提案图回退。加载时确认固定权重与 Target 数值相同，并验证在线引用相同 GPU 存储。
- 本机独立复算 420 条记录、各组接受与验证总数、接受率和当前模型参照倍率，与保存汇总一致。
