# 成本路线 B1：Feature 条件收益分析

目标：解释现用 PF-K2 在什么上下文中带来更多有效推进，以及生成前的信息能否预测这种差异。本轮不训练神经 Draft，不增加 P₂ Head，不实现在线策略选择。

## 数据与口径

- 沿用 A1–A3 的 10 个开发来源、28 个场景与初始长度组合、两个生成种子。
- 重放 56 条 PF 轨迹，逐 Token 与原结果比较；采集 5,078 个完整候选轮次的概率标签。
- 重放 56 个固定前缀中的 448 次 PF 单轮试验，与原输出、分支和计数比较。
- 时间和推进量始终来自 A1–A3 的 896 次低干扰单轮记录，每种方法每个前缀 8 次。概率补采时间不用于评价速度。
- 置信区间以来源为抽样单位，报告来源等权的几何平均速度比；同一来源的轮次不视为独立场景。

## 三个量

给定固定前缀及 Ranker 的首个位置候选，记录：

\[
A_P=p_T(P_1\mid h),\qquad
A_F=\sum_f\min\{p_T(f\mid h,P_1),q_F(f\mid h,P_1)\}.
\]

Position 使用点分布提案，因此连续接受首个 P/F 的概率为 \(A_PA_F\)。在没有 EOS 的普通轮次中，推进量为 \(2+2\mathbf1(P_1,F_1\text{ 均接受})\)。EOS 另行统计，有限长度结尾不能直接套用这个式子。

- `G`：同一前缀中 PF 与 P-only 的平均推进 Token 差。
- `C`：同一前缀中两种方法的平均完整轮次时间差。
- `C` 包括第二次位置提案、较长 Target 验证及分支处理的净变化，不能解释为 MLP 单独的耗时。

## 信息可用时间

候选生成前：历史长度、最近位置间隔、位置坐标、首个候选的间隔与坐标变化、候选数量、已有 Ranker 得分与分差。Ranker 得分属于排序模型输出，不能直接当作接受概率。

Feature 草稿生成后：`q` 的熵、最大概率、概率分差、非零支持数量。取得这些量已经支付 Draft 与概率处理成本；本轮不据此宣称策略切换加速。

Target 验证后：精确 `A_F`、`A_P`、连续接受概率。这些量只作为诊断标签，不能成为生成前预测器的输入。

## 分析设计

先报告初始前缀、中间前缀、上下文长度、位置间隔，以及诊断标签分位组的同前缀收益。组间内容和长度同时变化，分组差异不能归因于单一因素。

预测能力使用固定 `StandardScaler + Ridge(alpha=10)`，按来源留一验证；所有同来源场景、轮次与重复均进入同一折。分别预测精确 Feature 重合度、同前缀推进差和时间差。参数不根据结果搜索，不实现在线调度器。训练均值预测作为简单参照。
